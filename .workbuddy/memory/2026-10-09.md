### 新增的仓库级文件
- `.gitattributes` —— **强制 LF**（`* text=auto eol=lf`，`.bat/.cmd/.ps1` 保留 CRLF）。原因：husky 的 shell 钩子若变成 CRLF，在 Linux/macOS 上会因 `\r` 执行失败。
- `package.json` 本地配置 `core.autocrlf=false`，与 .gitattributes 配合。

### Husky 挂载方式（重要）
- 仓库根是 `BlueWhale/`，而 husky 在 `web/`，**因此无法用 husky 的自动安装**（且本机沙箱下 Node spawn git 报 `EBUSY`）。
- 解法：Git 原生 `git config core.hooksPath web/.husky`（本地配置，不入库）；同时在 `web/package.json` 保留 `"prepare": "husky"` 供其他环境自动挂载。
- 钩子脚本内部必须 `cd "$(git rev-parse --show-toplevel)/web"` —— Git 执行钩子时 cwd 是仓库根，而 pnpm/lint-staged 需要 web/。
