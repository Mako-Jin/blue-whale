### Husky 挂载方式（重要）
- 仓库根是 `BlueWhale/`，而 husky 在 `web/`，**因此无法用 husky 的自动安装**（且本机沙箱下 Node spawn git 报 `EBUSY`）。

## 新增公共能力包 common-tools + 公共依赖治理（catalog）

舰长要求：查看 `platform-terminator/packages/common-tools`，给新项目加一个存放公共内容的包，并把其中的 logger「颜色、格式、层级、配置」全部优化。

### 一、先回答"存放公共依赖的包"

**结论：不需要这样的包。** "公共依赖"其实是两件事，混在一起两头都错：

| 诉求 | 正确做法 |
|------|----------|
| 第三方依赖的**版本**统一管 | pnpm **catalog**（写在 `web/pnpm-workspace.yaml`） |
| 自研**公共代码**复用 | `packages/common-<能力>` 包 |

- 建"存放依赖的包"会产生**幽灵依赖**：库能被引用到，却没出现在引用方的 `package.json` 里，运行时解析不到、IDE 也提示不出来。
- catalog 只统一版本号，依赖归属仍留在各自 `package.json`，两者兼得。

### 二、已落地：pnpm catalog

`web/pnpm-workspace.yaml` 新增 `catalog:`（32 个公共依赖），4 个 `package.json` 全部改写成 `"catalog:"`：

- `web/package.json`、`packages/common-config`、`packages/common-tools`、`platform/platform-portal`
- `peerDependencies` 有意保留区间写法（peer 表达的是兼容范围，不是锁定版本）
- `pnpm install` 验证通过，版本解析结果与改动前完全一致（无意外升级）

### 四、logger 重写要点（原实现修复 16 项，详见包 README）

最实质的四条：

1. **级别只映射到 `console.log`** → 改成 `debug`/`log`/`warn`/`error`，恢复 DevTools 级别筛选与错误堆栈定位。
2. **`timestampFormat` 分支被整段注释掉** → 配置形同虚设，现在五种格式真正生效 + 支持自定义函数。
3. **主题是浅合并** → 只传 `{ info: { fg } }` 会让该级别 bg/border 变 `undefined`；改成按级别按字段深合并，并把散落的硬编码色值收进 `palette`。
4. **只用 `%c` 渲染** → Node/CI 里打印出 `%c color:#...` 噪音；改成三态自适应 `css`/`ansi`/`plain`。

另外：7 级严重度 + 阈值过滤（过滤前置于格式化）、命名空间层级 `child()`、`withContext`、`LogSink` 输出通道（可捕获/镜像/上报）、全局配置惰性解析（修复"先建实例后 configure 不生效"）、消息里 `%o`/`%c` 转义、`showBanner` 不再默认 `console.clear()`、`env` 不再直接访问 `window`。

### 八、提交过程中钩子又抓到两个问题

`git commit` 时 pre-commit 钩子真实拦截，暴露两处：

1. **新包缺 `stylelint.config.js`** → stylelint 按**文件位置**向上找配置，`playground/style.css` 找不到任何配置，直接报 `ConfigurationError`。
   解法：补 `packages/common-tools/stylelint.config.js`（一行 `export { default } from 'common-config/stylelint';`，与既有约定一致），并加 `stylelint` 脚本。

2. **构建产物被当成源码 lint** → playground 原本输出到包根 `dist-playground/`，而共享配置只忽略 `**/dist/**`，于是 `npx eslint .` 报了 30 个 `no-undef`（产物里的 `document` / `window`）。
   解法：产物改输出到 `playground/dist`，**自动复用** `**/dist/**` 忽略规则与 `.gitignore` 的 `dist/`，不再为单个目录加例外。
