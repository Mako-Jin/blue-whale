## 【前端基座】搭建并跑通 web/ 工程（舰长手动清空后重建）

舰长手动删除了照搬参考项目的子项目，要求：先搭前端，pnpm monorepo + Turborepo，React + TS，规范工具链齐全。

### 舰长确认
- **采用 Turborepo**（理由：qiankun 多应用 dev 日志聚合、依赖拓扑启动；后期缓存回本）

- 规范工具链：**ESLint + Prettier + commitlint/Husky/lint-staged + Stylelint + Vitest**
- 样式方案：**Less**

### 版本决策
- 生态版本（2026）：React 19.3、Vite 8.3、ESLint 10.12、Turbo 2.11、Vitest 5、Stylelint 17
- **TypeScript 用 6.0.3，不用 7.x** —— `typescript-eslint` 的 peer 要求 `<6.1.0`，TS 7 太新尚不支持

### 产出结构
- `web/` 根：`pnpm-workspace.yaml`、`turbo.json`、`.prettierrc.json`、`commitlint.config.js`、`.editorconfig`、`.husky/`、根 `package.json`（含 lint-staged 配置）
- `web/packages/common-config/` —— 共享工程配置包（packages 下唯一包）
  - `src/eslint.js` → 导出 `createEslintConfig(options)` 工厂函数
  - `src/stylelint.js` → 导出配置对象
  - `src/tsconfig.base.json` / `tsconfig.react.json`
- `web/platform/platform-portal/` —— qiankun 主应用，含 vite.config / tsconfig / eslint.config / stylelint.config / index.html / src 骨架（main、App、router、BasicLayout、Home 页 + less、variables.less、test/setup、Home 单测）

### 踩坑与修复（重要，勿重蹈）
1. **TS 6 弃用 `baseUrl`** —— tsconfig 里不能再写 `baseUrl`（TS 7 将移除），`paths` 现已相对 tsconfig 自身解析，直接删掉即可。
2. **ESLint 默认导出必须是数组** —— `eslint.config.js` 若 `export { default } from 'common-config/eslint'` 会把**函数**交给 ESLint，报 `TypeError: Unexpected function`。正确写法：`import { createEslintConfig } from 'common-config/eslint'; export default createEslintConfig();`
3. **Stylelint + pnpm 隔离找不到 extends 包** —— 共享配置里 `extends: ['stylelint-config-standard']` 字符串会按**子项目目录**解析而失败；`configBasedir` 实测无效。解法：在 `common-config` 内用 `createRequire(import.meta.url).resolve(...)` 解析成绝对路径。
4. **Stylelint 误报 Less 变量** —— `declaration-property-value-no-unknown` 不认 `@var`，已在 `**/*.less` override 中关闭该规则。
