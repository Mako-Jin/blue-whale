## 5 后端 / 权限域（跨切面不变量）
- 依赖 `sts-app→sts-server→sts-components→sts-common→sts-parent`（`<version>` 只在 parent）；`sts-app-server` 唯一可启动；**按特性分包**；**业务失败返 HTTP 200**（判 `code===0`）。Boot4 starter 三处同动（`web→webmvc`、`boot3-starter→boot4-starter`、springdoc `2.x→3.x`）；Jackson3 import `tools.jackson.*`；enforcer `[21,)`。**Flyway**：不写 `IF NOT EXISTS`、**已执行脚本不可改**、**版本号全仓唯一**；切 mysql 须引 `flyway-mysql`；达梦 `flyway.enabled=false` 走 `scripts/init-dameng.sh`（**未用真实实例验证**）。MySQL 保留字正解**属性名与列名同构**且不加 `@TableField`；两库保留字**不可互推**。**append-only 事实表不继承 `BaseEntity`**
- **权限域** `bw_auth_*`、错误码 `40001~40918`；自研 HS512+PBKDF2、**不引 Spring Security**；`@RequiresPermission`+`AuthInterceptor`（**白名单反着写：无注解即公开**）；`AuthTokenFilter` 不可同时 `@Component` 又进 `FilterRegistrationBean`。当前权限项：admin **45** / auditor **14**（含 18 条 `ui:` 菜单码）
- **三条必须反复问的静默缺陷**（共同点：写了但不生效、**且不报错**）：
  ① **凡新增影响权限的开关 → 问"判定里读它了吗"**（已抓 5 处：DENY 跨角色 / 停用角色 / 时态 / **停用用户组** / 组链路时态；**判定越严、反查越宽**；**嵌套组判定只跳一层** → `bindMember` 拒绝 `GROUP` 兜住）
  ② **软删 + 唯一键**（资源/角色/用户组同坑）：唯一键**不含 `deleted`** → 重建同码**撞键** → 正解**复活原记录**并**一并清空成员与授权**（`40900` 由 `DuplicateKeyException` 处理器填上；`spring-tx` 在该模块必须 **compile**）
  ③ **`updateById` 的 `NOT_NULL` 清不掉字段**（传 null 进不了 `SET`、0 行不报错）→ 用 `update(new Entity(), lambdaUpdate().set(...))` **逐列显式 set**、传**空实体**
- **数据范围（0025/0030）** 只做**求值 + 下发**、**取最宽**（ALL5>DEPT_AND_CHILD4>DEPT3>CUSTOM2>SELF1）；`precise` 区分"已配置/已生效"；**算不出往窄兜底**（只 ALL 放行全租户）。`DEPT` 系列**可精确求值**（有有效主岗才 `precise=true` 并下发 `visibleOrgIds`）。**本仓无业务数据表** ⇒ 过滤业务数据**无落点**；**把 `DEPT` 接进审计是静默放宽 ⇒ 刻意不做**。`CUSTOM` 的 `filter_json` 解析**未实现** ⇒ **角色表单不提供该档**（后端枚举保留、求值给 `precise=false`），存量 CUSTOM 行在编辑框里按**历史值**显示
- **组织域（0030）** 层级=**物化路径**（`org_level`/`code_path`/`full_name` 是 `parentId` 与节点名的**确定函数** ⇒ **不接受入参**）；`code_path` 前缀**同时是求值口径与重写边界**；**移动是独立接口 + 独立动作**（重写整棵子树 ⇒ 子树上每个人的范围同时变；带不同 `parentId` **显式 40001**，与用户组 `parentId` **判断相反**）；**移动必须显式落 `parent_id`** —— 曾只写派生列 ⇒ **范围已搬家、树还显示在原地、两处都不报错**（抓它的断言是"移动后**原父级 `hasChild` 归 0**"）；**主岗三规则**：每人每租户至多一个（**该表连唯一索引都没有**、全靠服务层）、**不静默搬主岗**（不传时：没主岗→自动设、已有→保持）、**时态参与求值**；无归属时设主岗 `40410`；删除两码分开（`40913`/`40919`）、**无级联**。前端坑：**`OrganizationTreeNode` 与 `OrganizationVO` 不是子集关系** ⇒ **拿树节点填编辑表单会以空值提交**（"只改个名字"顺手清掉几列）⇒ **树给结构与导航、详情给表单初值**（`openEdit` 必须先 `detail(id)`）；组织**编辑态不渲染上级选择器**；「是否主岗」是**三态** `'' | '1' | '0'`；`visibleOrgIds` 的 **`null` 与 `[]` 必须显示成两句不同的话**
- **审计可见性（0025）** 租户**无条件**强制、`operatorId` 只在 ALL 档生效、跨租户详情 **404 非 403**、`countByAction` 必传 `tenantId`
- **日志/事件准入（0026）** **上报公开 / 查询鉴权**；新域前缀 `log:client`/`event:client`（登记在 `AuthPermissions.ALL`，**全仓唯一登记处**）；**归属只取服务端会话**（事件里的 `user_id` 是上报方填的、**不是归属依据**）；租户条件**恒定加上、不做成可关形式**；聚合手写 SQL **参数必传**；跨租户 **404 且"不存在/不是你的"同码**；**历史数据不回填**。**`listByTraceId` 已补 7 天窗 + 200 条上限（0032）** —— 用**分页插件**而非手写 `LIMIT`（双方言）；**同批上报的 `serverTime` 相同**（循环外只算一次）⇒ 排序**必须补 `id` 次级键**
- **菜单权限（0031）** `ui:` **是新权限域、性质与前所有域都不同**：`MENU`/`PAGE` 的 `requestScoped=false`、**没有任何 `@RequiresPermission` 会写 `ui:*`** ⇒ **菜单码是布局、读权限是安全边界**；撤销菜单码**不拦接口**、**不是权限收窄工具**（合并成一层 = 把"少看到一个入口"升级成"真的少做一件事"）。仍须登记进 `AuthPermissions.ALL`（种子由它建出，漏了 = 入口**永远不出现**）；结构在 `AuthMenus`（`AuthMenuTaxonomyTest` 钉住）、前端 `common-api/menus.ts`（`menus.test.ts` **逐字**钉住）⇒ **改码必须同改两端**；**菜单不进 OpenAPI**。基座**两步同做**：`BasicLayout` 过滤 + `RequireMenu` 拦 URL 直达（**只做前者 = 地址栏成后门**）；`menuPermission` **必填**；**概览页也过滤**并解释 `state.denied`。**三维环境只有应用级码**（场景不承载数据 ⇒ 页面码是假开关；且它不需会话，引认证会**弄坏"后端没起时单跑看渲染"**）。**看不见的东西不发请求**（提前 return）。粒度：日志/事件各两栏（**详情抽屉跟右栏**）、审计三块（**演练按钮刻意不显隐**）、admin 六标签页（「组织」末尾）。**排序四处对齐**（`AuthMenus`=`menus.ts`=`TABS`=`MICRO_APPS`）。权限 store 在 `common-tools/micro`（`createPermissionStore`，**不引 React**；**判据是"有没有宿主桥"不是"有没有会话"**；`ready` 看 `userId` 非空）
- **上报限流（0027/0028）** 归**网关层**（`infra/nginx/`，应用与前端**零改动**）；`42900` 由**网关**产生。**两层阈值性质不同**（病根：把"隔离"与"容量"压在同一阈值上）：按 IP（`$bluewhale_report_key`）=**隔离**（按最大 NAT 出口算 `N/3 r/s`）；全局（常量 key）=**容量**（按后端吸收速率、**与人数无关**）。**429 ≠ 丢弃**：`BatchChannel.flush()` 失败把整批 `buffer.unshift()` **退回队首**、退避 `min(interval×2^n, 30s)`、装不下才 `dropped`；`push()` 溢出丢**最旧** ⇒ 短暂超限=延迟、持续超限=丢最旧一批
- **种子口令（0029）** 两个 `password` **清空**（有默认值 ⇒"开种子 + 不覆盖口令"就得到一个**口令公开可查的管理员**）；开种子不给口令**拒绝启动**（校验**提到所有落库之前**）；开发口令真值来源**全仓唯一**在 `application-h2.yml`；凭据副本收敛 `scripts/lib/seed-credentials.mjs`。⚠️ `@Schema(example)` **只落 JSDoc、不进产物** —— 把口令带进包的是**登录页把口令印在页面上** ⇒ 门控 `import.meta.env.DEV`，**验证靠构建后 grep 产物**
