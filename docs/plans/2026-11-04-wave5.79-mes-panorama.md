## 0. 结论与当前状态

| 项 | 结论 |
|---|---|
| 现状 | `whale-mes` 仅有 `mes_work_order`（1 张业务表 + `api_log`）、5 个工单 CRUD 端点、`ENABLED/DISABLED` 启停字段；前端仅列表/表单弹窗 |
| 目标 | 按七大模块补齐，保持 **单服务、单库、模块化分包**（9002 / `/mes/**` / `bluewhale_mes` / 前端 8105） |
| 交付方式 | **M0 → M5** 分阶段，每阶段独立可构建、可验收、可回滚；每阶段结束产出检查报告 |

| 模块顺序 | **模块编号 ≠ 交付顺序**：质量、OEE、绩效依赖报工数据，统一排在执行层之后 |
| 当前阻塞 | ~~16 项业务规则待确认（设计稿 §十一 D1–D16）~~ **已随 M0–M5 实现按推荐口径落地（2026-11-05）**；实现取值为规划推荐默认，**业务确认仍欠一次复盘**——若与现场口径不一致需按变更流程回改，属返工风险而非进度阻塞 |
| 本波产出 | 设计稿、实施计划、需求登记（REQ-FUNC-057..063 / REQ-ARCH-021 / REQ-SEC-031）、权限/菜单/角色预留；**不写业务代码** |

## 1. 范围

### 1.1 包含

- 生产调度与派工：工单接收、拆分、派工、有限产能排程 MVP、进度跟踪、生产看板。
- 生产执行：任务状态流转、扫码报工、领料/退料/补料、在制品、异常上报与流转。
- 车间质量：首件检验、IPQC 巡检、不良品与处置、返工/返修/报废、SPC、质量追溯。
- 设备管理：台账、状态监控、OEE、保养计划、维修、备件。
- 物料与追溯：条码/RFID、批次谱系、物料防错、线边仓、正反向追溯。
- 数据采集：设备/采集点、人工报工终端、生产看板、数据归档。
- 人员与绩效：班组、排班、交接班、实际工时、个人/班组绩效。
- 跨域集成：ERP、PDM、OA/Workflow、`whale-file`、`whale-message`、auth/audit。

### 1.2 不包含（明确划出）

| 不做 | 归属 |
|---|---|
| 生产订单主数据、总库存、财务凭证、质量成本、固定资产折旧 | ERP（MES 只接收/回传执行结果） |
| BOM 与工艺路线主数据建模、版本发布 | PDM（MES 只存执行版本快照） |
| 请假、加班、超领、让步/报废审批流引擎 | OA / `whale-workflow` |
| 员工主档、薪资计算、个税社保 | ERP HR / OA（MES 只引用员工 ID） |
| 客户关系、供应商准入、合同、支付 | CRM / SRM / `whale-contract` / `whale-pay` |
| 设备控制指令下发、PLC 组态、SCADA 历史库 | 设备系统/边缘网关（MES 只读采集） |
| 高级 APS 优化、AI 预测性维护、Andon 硬件 | 后续增强，不在 M0–M5 |
| 拆分为多个微服务 | 明确否决（见设计稿 §8.1） |

### 3.3 M0+M1 验收口径（端到端）

1. ERP 通过内网下发 1 张生产订单 → MES 幂等接收，重复下发不重复建单。
2. 按工艺路线拆分 3 道工序 → 派到 2 条产线/3 个机台，拆分量之和等于计划量。
3. 操作员扫码开工 → 分 3 次报工（合格/不良）→ 暂停/恢复 → 完工；累计报工不超派工量。
4. 领料/退料后线边台账不为负；在制品数量与报工汇总一致。
5. 异常上报 → 通知 → 处理关闭；处理记录可追溯。
6. 看板今日目标/完成数/异常数/达成率与数据库抽样一致。
7. 完工回传 Outbox 生成待发送事件；重复重试不重复记账（ERP 端点未就绪时标记待发送）。
8. 旧 `/mes/work-order/**` 5 端点仍可用，前端已迁移到新路由。

## 4. 各里程碑要点

### M2 物料与追溯（3–5 周）

- 条码规则与生成：Code128/QR、批次码/序列号、标签打印载荷；打印硬件由现场标签系统承接。
- 批次与谱系：来料批次、半成品批次、成品批次；正追溯/反追溯；谱系无环、消耗量 ≤ 投入量。
- 扫码防错：工位/工序/物料/批次校验规则；上错料阻断并报警；重复扫码幂等。
- 线边仓：线边库存、流水、实时扣减、缺料叫料；补货走 ERP 库存调拨（`/erp/scm/transfer` 已具备）。
- 验收：条码唯一；错料扫码拒绝；正反追溯 3 层完整；线边库存 ≥0；补货请求幂等；追溯查询 P95 <3s。

### M3 车间质量（4–6 周）

- 检验计划：首件、IPQC 频次/抽样方案；检验项与判定规则可配置。
- 首件门禁：首件未通过不得批量释放/继续生产；失败自动生成 NCR。
- 不良品与处置：返工/返修/让步/报废；处置数量 = NCR 数量；返工单回链执行任务。
- SPC：Xbar-R（默认）+ 规则配置；样本来自检验/采集；规则命中告警并留痕。
- 质量追溯：按批次/工单/设备/操作员反查；与 M2 谱系联动。
- 验收：检验项未完成不可判定；`FAILED` 必生成 NCR；处置闭环；SPC 规则可配置；质量看板与检验记录一致。

### M4 设备与数据采集（5–7 周，**已落地 2026-11-04**）

- 设备台账：编码、参数、所属车间/产线、保养周期、状态基线。
- 状态与 OEE：运行/待机/故障/保养/离线事件流；停机时长；OEE 按班次/设备快照；公式可配置（D12）。
- 保养/维修/备件：计划到期提醒、保养工单与验收、报修派工与验证、备件库存与领用流水。
- 数据采集：设备/采集点注册；边缘网关推送 `/mes/internal/collect/{pointCode}`；样本幂等；看板配置；归档策略。
- 验收：故障设备不可开工（或强警告+审批，按 D11）；OEE 与状态/产量抽样一致；保养到期提醒；备件库存 ≥0；采集样本重复不重复入库；归档任务可重跑。

### M5 人员绩效与收口（3–4 周）

- 班组与排班：班组成员、班次排班、交接班记录；同工位同班次主操作员唯一。
- 工时与绩效：实际工时（开工/完工/暂停区间）、标准工时（工艺路线快照）、个人/班组产量/合格率/效率；月度锁定。
- 收口：综合看板（生产/质量/设备/人员）、导出权限、归档/保留策略、SLO 与运维手册、端到端验收脚本。
- 验收：工时与报工抽样一致；绩效月度锁定后不可改；综合看板指标口径一致；导出受权限码控制；运维手册可执行。

### 后续增强（不在本波）

APS 高级排程、AI 预测性维护、Andon 硬件、离线报工队列、多工厂/多车间集团视图、RFID 批量识别、SPC 高级图型（EWMA/CUSUM）、设备直连 OPC UA/Modbus 插件。
