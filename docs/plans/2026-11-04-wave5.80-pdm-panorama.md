## 一、计划结论

1. **一次性铺完 7 个模块不现实，也不安全**。PDM 当前只有产品档案（1 张业务表、5 个端点、2 个前端页面），而图文档、版本、BOM、变更、工艺都是硬骨头。按 M0–M5 六个阶段推进（其中 M1 拆 M1A/M1B），每个阶段独立可构建、可验收、可回滚。
2. **先做「图文档 + 版本 + 权限」底座，再做「零件 + EBOM」**。BOM 离开版本化文档和零件主档就只是一张表；变更离开已发布基线就无法追溯。顺序倒置会返工。
3. **首个切片 = M0 + M1A**：图文档中心（存储/分类/版本/ACL/检索）+ 零件主档扩展 + EBOM 结构树 + BOM 发布快照契约。**M1A 的 BOM 快照契约同时解除 ERP M3 剩余 MRP 的阻塞**（见 ERP 计划 §13.4）。
4. **不新增服务、不新增数据库、不新增前端子应用**：仍为 `whale-pdm`（9003 / `/pdm/**` / `bluewhale_pdm` / 8106），按 5 个业务上下文 + 1 个集成层分包；跨域只走内网 REST。
5. **审批不复制**：ECR/ECO/评审审批走 OA/Workflow；**项目/任务/甘特不复制**：归 `whale-pm`；PDM 只做交付物归档与评审记录；**文件字节不复制**：归 `whale-file`。
6. **在写第一行业务代码前，必须确认 D-PDM-1..10**（版本号规则、零件/ERP 主数据归属、CAD 预览方案、BOM 同步方式、PBOM/MBOM 深度、MES 契约、项目归属、存储配额等）。本计划默认值见设计稿 §十一。

## 三、范围与边界

### 3.1 本计划包含

- 图文档：存储（引用 `whale-file`）、多级分类、文档主档、版本、检出/检入、文件夹/文件 ACL、授权下载/预览、多维检索。
- 产品结构：零件/产品主档（含标准件、通用件）、物料分类、去重建议、EBOM/PBOM/MBOM 视图、BOM 对比/导出/发布快照。
- 版本与变更：版本号规则、ECR、ECO、ECN、影响对象、变更任务、追溯、生效日期与生效任务。
- 工艺（轻量）：工艺路线、工序、工时定额、工装夹具、SOP 引用、下发 MES。
- 协同：项目交付物归档（引用 `whale-pm`）、设计/样机/转产评审记录与结论。
- 集成：CAD 侧 REST 契约与示例脚本、ERP 物料/BOM 同步、MES 路线/SOP 下发、OA 审批发起与回调、同步记录/重试/对账。
- 权限、菜单、角色、审计、迁移与前端页面。

### 3.2 本计划不包含

| 不做 | 归属 |
|---|---|
| 审批流引擎、审批定义、会签/加签 | OA / `whale-workflow` |
| 项目立项、任务派发、迭代、看板、甘特 | `whale-pm` |
| 通用 Wiki、在线协作文档 | `whale-doc` |
| 文件字节存储、分片上传、Range 读取 | `whale-file` |
| 采购/生产物料主数据、库存、采购价格 | ERP |
| 车间工序执行、报工、设备采集 | MES |
| SolidWorks/AutoCAD/Pro-E 插件本体、安装包与签名 | 独立桌面客户端交付（本仓库只提供契约、示例与冒烟脚本） |
| 3D 引擎/WebGL 共享包改造 | 冻结中的 `whale-common-three`，本波不依赖、不解冻 |
| 微服务拆分、独立 PDM 数据库 | 不做 |

### 5.3 验收口径（DoD）

- 新建文档 → 上传图纸 → 草稿 `V0.1` → 发布 `V1.0` → 检入生成 `V0.2` → 再发布 `V1.1`，版本链完整；已发布版本的元数据与文件不可改。
- 同一文档同一时间只允许一人检出；他人检入返回 `DOC_CHECKED_OUT`；释放锁后可继续。
- 文件夹 ACL 继承生效；显式 `DENY` 覆盖 `ALLOW`；无下载权限时下载代理返回 403，且**不能**通过 `fileId` 绕过。
- 跨租户按 ID 查询文档/版本/ACL 均返回 404（不泄露存在性）。
- 检索能按零件号、文档名、设计师、日期区间组合过滤；列表 P95 < 300ms（种子 1 万文档压测）。
- 重启后 Flyway 从空库可重放；`/pdm/product/**` 旧接口与响应不变。

## 六、M1A：零件主档 + EBOM + 发布契约（4–5 周）

### 6.1 目标

建立「成品 → 部件 → 零件 → 原材料」结构树，并把**不可变 EBOM 快照**发布给 ERP，解除 MRP 阻塞。

### 6.2 任务分解

| 编号 | 任务 | 交付物 | 依赖 |
|---|---|---|---|
| M1A-1 | **扩展 `pdm_product` 为零件/产品主档**：`part_type`（PRODUCT/ASSEMBLY/PART/RAW_MATERIAL）、`material`、`spec`、`uom`、`category_code`、`erp_item_code`、`source_type`（STANDARD/COMMON/UNIQUE）、`status` | `V3__part_bom.sql` + 旧端点兼容 | M0 |
| M1A-2 | **物料分类**：树形分类、按材质/规格/用途筛选；标准件、通用件标记 | `pdm_part_category` + 端点 | M1A-1 |
| M1A-3 | **BOM 结构树**：`pdm_bom` / `pdm_bom_line`；父子无环、用量 > 0、装配约束、行序号唯一；树查询 5 层/1 万节点 | BOM 服务 + 环检测 + 查询端点 | M1A-1 |
| M1A-4 | **BOM 发布**：状态机 `DRAFT → RELEASED`；发布时冻结结构并生成快照（`pdm_bom_release`），`bomNo + versionNo + checksum` 唯一；重复发布返回既有记录 | 发布服务 + 快照 DTO | M1A-3 |
| M1A-5 | **ERP 快照契约**：`GET /pdm/internal/bom/{bomNo}/versions/{versionNo}` 返回稳定 JSON（产品编码、版本、行路径、子件、用量、单位、损耗率、生效期、校验和）；ERP 按 `bomNo + versionNo` 幂等落 `erp_bom_snapshot` | 内网端点 + 契约文档 + 契约测试 | M1A-4 |
| M1A-6 | **零件关联**：零件挂接文档版本、BOM 使用处（where-used）、ERP 物料映射字段 | 关联端点 | M0、M1A-1 |
| M1A-7 | **前端**：零件库列表/详情、BOM 树编辑器（增删行、改用量、展开/收起）、发布确认与快照查看 | 页面 + 组件 | M1A-3 |
| M1A-8 | **权限/菜单/角色**：930–949、菜单 185–189、角色 `pdm_engineer`(21104) | 幂等迁移 | M0-9 |

### 6.3 验收口径（DoD）

- 成品 → 部件 → 零件 → 原材料 4 层树可建、可改、可删；加入自身或后代作为子件返回 `BOM_CYCLE_DETECTED`。
- 发布后 BOM 与快照不可改；再次发布生成新版本；重复发布同一版本返回既有快照（幂等）。
- ERP 契约测试：同一 `bomNo + versionNo` 拉取两次结果一致，`checksum` 稳定；行顺序稳定；跨租户/不存在返回 404。
- 零件按 `partNo` 唯一；标准件可被多个 BOM 复用；零件停用后不能加入新 BOM。
- 前端 BOM 树操作不整树重渲染，1 万节点可展开/滚动可用。

## 十二、跨域接口清单（本计划承诺的契约）

## 十五、风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 版本规则未定，先写代码 | 版本表/变更流程返工 | M0-1 先定 D-PDM-4；版本逻辑集中在 `VersionNo`，不散落 |
| ACL 设计过粗，后期补文件级权限 | 安全漏洞与返工 | M0 就做文件夹继承 + 文件显式 ACL + DENY 优先；下载走代理不暴露 `fileId` |
| CAD 预览依赖商业转换器 | 功能延期、成本不可控 | D-PDM-3 先确认；M4 只承诺 PDF/Office/STEP→glTF；DWG 默认下载 |
| PBOM/MBOM 范围膨胀 | M1 拖期 | EBOM 先落地；PBOM/MBOM 做派生只读视图，人工调整走变更 |
| 零件主数据与 ERP 双头 | 物料口径不一致、MRP 错 | D-PDM-2 明确归属；字段白名单 + 幂等 `pdmPartNo` + 对账 |
| ERP/MES 接口未就绪 | 阻塞 M2/M3 | 定义契约与状态占位；外部不可用只落 `FAILED/PENDING`，不阻塞本地业务 |
| 审批回调重复/乱序 | 变更状态漂移 | `approvalInstanceId` 唯一索引 + 状态机校验 + 人工补偿入口 |
