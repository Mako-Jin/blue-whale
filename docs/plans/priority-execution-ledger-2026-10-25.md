## 二、执行规则

1. **文档先行**：编码前先更新评估稿/需求登记；每批代码产出 `docs/reviews/` 检查报告。
2. **单步闭环**：一项完成 → 构建/单测/Checkstyle 验证 → 提交并推送 `origin/main` → 更新本台账状态。
3. **阻塞不重试**：需要口令、外部环境或人工操作的项标记 `已阻塞`，先推进不依赖它的下一项。
4. **完成即划线**：已完成项保留删除线与完成结论，不删除历史。
