**计划结论：**

1. **29 个子模块无法一次铺完**。按 M0–M6 七个阶段推进，每个阶段独立可构建、可验收、可回滚；首个切片 **M0 底座 + M1 客户主数据**。
2. **客户是地基**。客户分级、查重、公海、跟进、画像、360 不成立，线索转化、商机、合同、工单、营销都没有可靠的客户引用和数据权限归属。
3. **销售过程是核心**。M1 完成后立即做 M2 线索/商机/漏斗/报价/预测/目标；报价审批走 `whale-workflow`，CRM 不复制审批引擎。
4. **商务履约必须切清**。合同正文/模板/签署/归档归 `whale-contract`；CRM 只做合同台账投影与续约任务；CRM 商务订单审批后幂等下发 ERP，ERP 仍是发货/库存/应收/信用/记账的唯一所有者。
5. **售后与营销可后置且可部分并行**。M4 依赖客户与订单；M5 依赖客户与线索；两者在 M2/M3 稳定后可并行；M6 最后收口分析、行动计划和导出。
6. **必须避免客户双头**。ERP 已有 `erp_customer` 业务主数据，ERP 设计稿 D9 未定稿。本计划推荐 CRM 为客户关系上游、ERP 保留业务扩展字段，但 **D2 未确认前不写客户同步代码**。
7. **编号主动避让**：ERP 355–599 / 63–119；PDM 900–1099 / 180–219；MES 1100–1399 / 240–299；OA 1600–1799 / 360–409 / 25123–25127。CRM 使用 **权限 1800–1899、菜单 410–449、角色 25128–25132**。
8. **首切片已按 M0-2/M0-3/M0-4/M0-9 落地**（分包 + V2/V3 迁移 + 权限角色 + 架构/单测/迁移测试）；M0-5 数据范围、M0-6 集成底座、M0-7 前端、M1-4 合并、M1-9 导入导出按里程碑后置，偏差见 [CRM 服务设计稿](../design/crm-service.md) §3.3。

## 1. 范围

### 1.1 包含

- **客户管理**：客户档案、联系人、地址、行业/规模/来源、A/B/C/D 分级、查重、合并、公海规则与领取/释放/分配、跟进记录、客户画像、客户 360、导入导出。
- **销售过程**：线索采集/分配/查重/转化、商机阶段机、销售漏斗、报价版本与审批、销售预测、销售目标、阶段停留与流失原因。
- **合同与订单**：合同台账只读投影、续约任务、商务订单、审批后幂等下发 ERP、回款计划/分期/催收/承诺、开票申请/记录/寄送跟踪、ERP 应收快照对账。
- **售后服务**：工单建单/分派/SLA/处理/升级/关闭/重开、知识引用与 FAQ 元数据、满意度问卷、退换货申请与 ERP 执行回读。
- **营销管理**：活动策划/预算/人群/线索归因/ROI、培育任务、邮件/短信/站内信批量触达（走消息服务）、渠道伙伴/授权/报单/业绩。
- **数据分析**：销售看板、漏斗分析、客户分析、销售排行、回款分析、规则化行动计划与导出。
- **工程范围**：六上下文分包、ArchUnit、Flyway V2–V9、权限/菜单/角色、前端 8113、审计/脱敏/数据范围、内网契约、outbox 重试、对账与告警。

### 1.2 不包含（明确划出）

| 不做 | 归属 |
|---|---|
| 合同正文、条款、模板库、印章、签署、归档、合同版本 | `whale-contract`（CRM 只做台账投影与续约任务） |
| 发货、库存、批次、应收台账、信用占用、坏账、记账凭证 | ERP |
| 审批流定义、会签/加签、审批待办 | `whale-workflow` |
| 邮件/短信/IM 的实际投递、供应商网关 | `whale-message` |
| 附件字节存储、分片上传、Range 读取 | `whale-file` |
| 知识正文、Wiki、AI 问答 | `whale-doc` / `whale-agent` |
| 项目/任务/甘特/迭代 | `whale-pm` |
| 佣金结算、开票记账、税务申报 | 财务 / ERP |
| 复杂营销自动化、AI 线索评分、机器学习预测 | 本波不做；留作后续增强 |
| 独立 BI 平台、数据仓库、跨库实时大屏 | 本波不做；CRM 只做本地快照 + 规则建议 |

### 3.3 M0+M1 端到端验收口径

1. 空库启动 `whale-crm` → Flyway 建表成功；`GET /crm/meta` 可用；门禁开关仍为 `false` 时业务接口不开放。
2. 新建客户「蓝鲸制造」→ 编码唯一；再建同名/同电话客户被硬冲突阻断；软冲突可确认后保存。
3. 建两个联系人并设一个主联系人 → 再设第二个主联系人被拒绝；删除主联系人后必须重新指定。
4. 把客户评级为 A → 列表/详情/导出显示 A；旧 `KEY` 数据映射为 A 并标注。
5. 配置「30 天未跟进自动回公海」→ 到期客户自动进入公海；销售 A 领取成功，销售 B 同时领取失败；释放后销售 B 可领取。
6. 新增电话/拜访/邮件跟进 → 客户最近跟进时间更新；下次动作到期触发消息提醒；跟进记录不可改删。
7. 编辑画像与决策链 → 决策链联系人必须属于该客户；变更留痕。
8. 打开客户 360 → 商机/合同/订单/工单/回款摘要可见；断开合同/ERP 桩后页面降级提示，不报 500。
9. 导入 10 行客户（含 2 行重复、1 行缺必填）→ 预检报告准确；执行后只新增 7 行；错误行可下载。
10. 销售 A 只能看本人/本部门客户；主管看下级；跨租户访问 404；导出需权限且脱敏；审计可查。

## 4. 各里程碑要点

### M2 销售过程（4–5 周）

- **线索**：来源（展会/官网/广告/导入/手工）、分配规则（轮询/区域/行业/指定）、状态机、线索活动、查重、转客户/商机（一次且幂等）、无效原因、回收。
- **商机**：`CONTACT → PROPOSAL → NEGOTIATION → WON/LOST`；阶段历史、停留时长、金额/概率/预计关闭、竞争态势、输单原因。
- **漏斗**：线索→初步接触→方案报价→谈判→赢单；数量/金额/转化率/停留时长/流失原因；按人/团队/来源/行业钻取。
- **报价**：头/行/版本；折扣、税率、有效期；提交审批（workflow）；已审批锁定；改价新版本；转订单。
- **预测**：管道/最佳/承诺；阶段概率加权；月/季快照；手工调整留痕。
- **目标**：个人/部门/月/季；签约合同额口径；完成率；调整审计。
- **验收**：线索只转化一次；商机非法阶段拒绝；WON/LOST 规则生效；报价审批回调幂等；预测公式可复算；目标完成率与合同/商机抽样一致；漏斗转化率 = 阶段计数比。

### M3 合同与订单（4–5 周）

- **合同台账**：按 `bizType=CRM_CUSTOMER` / `bizId=crmCustomerId` 查询 `whale-contract`；只存 `contractId/contractNo/amount/status/effectiveDate/expireDate` 投影；不复制正文；续约任务；合同变更回调/定时对账。
- **合同服务增强（跨服务）**：合同模板表与模板套用、合同查询增加 `bizType/bizId` 过滤、内网按业务查询、到期提醒任务/回调。若产品确认模板由合同服务承接。
- **商务订单**：从合同/报价生成 `crm_sales_order`；审批走 workflow；审批后 outbox 下发 ERP；ERP 增 `source_type/source_id` 与 `crm_order_no` 唯一键；回写 `erpOrderNo`；失败重试/对账；已发货不可取消。
- **客户映射**：按 D2 方案同步 `crmCustomerId` 到 `erp_customer`；ERP 增 `crm_customer_id` 唯一键；历史客户按税号/名称人工确认映射，不自动合并。
- **回款**：回款计划/分期金额合计 = 合同可回款金额；承诺还款；催收任务/优先级；ERP 应收快照只读；逾期/账龄口径与 ERP 对账。
- **发票**：开票申请/审批/记录/寄送跟踪；申请金额 ≤ 可开票金额；票面记账/税额归 ERP/财务；红冲单独流程。
- **验收**：合同正文不落 CRM；CRM 订单下发幂等（重复请求不重复建 ERP 单）；ERP 不可用时订单 `PUSH_FAILED` 可重试；已发货取消被拒；分期合计=合同金额；逾期与 ERP 抽样一致；发票状态机合法。

### M4 售后服务（3–4 周）

- **工单**：报修/投诉建单；客户/联系人/合同/订单/产品/序列号；分类/优先级/描述/附件；按产品/区域/技能分派；SLA 响应/解决时限；等待客户暂停；升级；解决/关闭/重开；处理记录追加式。
- **知识引用**：FAQ 元数据、产品/故障标签、可见范围、文档 ID/版本引用；搜索走 `whale-doc`；命中统计；正文不复制；文档服务不可用时降级为标题列表。
- **满意度**：工单关闭触发；HMAC 令牌、一次性、有效期、限流；1–5 分 + 评论 + 维度；低分自动生成回访任务；结果统计。
- **退换货**：退货/换货申请、原因、行/数量；审批走 workflow；ERP 销售退货执行；库存/应收红冲回读；CRM 不写库存。
- **验收**：工单状态机不可跳转；关闭必须有解决方案；SLA 暂停/恢复成对；问卷令牌不可重放；低分任务生成；退货数量 ≤ 可退数量；ERP 不可用时申请保留待执行。

### M5 营销管理（3–4 周）

- **活动**：展会/直播/促销/其他；预算/实际费用、目标人群、周期、渠道、负责人；人群快照锁定；线索/商机/订单归因；ROI。
- **人群**：行业/区域/等级/来源/标签/最近跟进/负责人；预览数量；锁定后不可变；排除退订/黑名单/无联系方式。
- **培育**：沉默客户/低意向线索培育任务；内容引用 `whale-doc`；手动/计划触达；不做复杂自动化编排。
- **触达**：邮件/短信/站内信走 `whale-message`；模板、批次、限流、重试、送达状态；每活动每联系人一次；退订/黑名单。
- **渠道**：伙伴档案、授权、报单、冲突校验、业绩统计；佣金结算不做。
- **验收**：人群预览数与发送数一致（排除退订后）；重复发送被幂等拦截；退订立即生效；ROI 可复算；报单冲突可裁决；活动归因链可追溯。

### M6 数据分析与行动计划（3–4 周）

- **指标与快照**：销售、漏斗、客户、排行、回款指标统一定义；每日 02:00 快照；`metricCode + statDate + 维度` 唯一；可重跑；保留 5 年。
- **销售看板**：今日新增线索、本周签单、本月目标完成率、预测缺口、风险商机、待办行动。
- **漏斗分析**：环节流失、转化率、停留时长、按人/团队/来源/行业钻取。
- **客户分析**：行业/区域/来源分布、新增/流失、A/B/C/D 结构、集中度。
- **销售排行**：个人/团队签单额、合同数、回款率；权限与口径受控。
- **回款分析 + 计划建议**：逾期金额/账龄、承诺履约率、重点逾期客户、催收优先级；生成 `crm_action_item`（责任人/截止日/建议动作），条件解除自动关闭，人工关闭需原因。
- **行动计划规则**（规则化，不做 AI）：A/B 客户 30 天未跟进、商机预计关闭逾期/无活动、目标缺口、合同 90 天内到期、逾期应收、低满意度工单、活动高意向线索未跟进。
- **导出**：CSV/Excel 异步导出；权限码 + 脱敏 + 审计；大数据量任务可重试。
- **验收**：指标定义有文档；快照重跑幂等；看板与源数据抽样一致；行动计划去重且可关闭；导出脱敏；看板 P95 < 3s。

## 6. 质量门禁（每阶段必须全绿）

1. **后端**：`mvn test` 全绿；Checkstyle 0；ArchUnit 全绿；新增代码行覆盖 ≥ 60%、分支 ≥ 45%（不低于 ERP M3 基线 57.6%/51.8%）。
2. **Flyway**：空库启动自动建表；脚本重复执行幂等；禁止 `DROP/TRUNCATE/DELETE`；`validate-on-migrate=true`；`clean` 禁用。
3. **权限矩阵**：每个端点有权限码；无权限 403；跨租户 404；数据范围抽样正确；未交付菜单不挂空入口。
4. **审计与脱敏**：写操作有 `@AuditLog`；日志/审计/导出不含完整手机号/邮箱/税号；导出有权限码。
5. **外部集成**：外部调用不入本地事务；重复回调/重复下发幂等；失败可重试；不可用可降级；`/crm/internal/**` 外部 403。
6. **前端**：`pnpm lint/build/test` 全绿；关键页面 E2E；权限按钮正确；大列表分页/筛选可用。
7. **文档**：设计稿、接口/指标口径、需求登记、检查报告、devlog 同步；偏差记录在对应 Wave 检查报告。
8. **发布**：模块开关默认关闭；灰度顺序按 M1→M2→M3→M4/M5→M6；回滚只回代码与开关，不回滚已执行 Flyway。
