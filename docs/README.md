# docs — 文档与契约

| 目录 | 内容 |
|------|------|
| `architecture/` | 整体架构说明、分层图、部署拓扑 |
| `api/` | OpenAPI 契约文件（**唯一真相源**） |
| `decisions/` | 架构决策记录（ADR） |

## 约定

1. **`api/` 是契约的唯一真相源。** 后端按契约实现，前端由契约生成 SDK，禁止任何一方私改字段。
2. **每个不可逆的架构决策都写 ADR。** 命名格式：`decisions/NNNN-简短标题.md`，包含背景、决策、后果三部分。
3. **文档随代码同仓维护。** 架构变了，文档在同一提交里改掉。
