## 五、遗留（P3 建议项）

1. **运行时/端到端未验证**：本机无 Docker，Redis 实机不可用；「登出 → 网关 401」「登出 → refresh 401」仅以 mock 单测证明逻辑，端到端待中间件就绪。
2. **降级语义**：Redis 不可用时两侧均按「未命中」放行，登出形同失效；生产需对 Redis 可用性监控告警（已写入 `distributed.md` §3.6）。
3. **refreshToken 轮换未实施**：本批仅「校验」失效，未做「一次一换」（旧 refreshToken 用后即废）；如需要可后续评估。
4. **jjwt 版本分裂**：网关显式 0.12.6 / 父 POM 管理 0.12.5，尚未统一，存在行为差异隐患。
