### 二、变更点

**1. admin 前端（4 新页 + 2 扩展 + 2 新 API）**

- 新建 `src/api/job.ts`（任务分页/新增/更新/删除/启停/立即执行 + 日志分页）、`src/api/file.ts`（分页/删除 + 原生 fetch 承载 multipart 上传与 blob 下载，不复用 JSON 信封客户端）。
- 扩展 `src/api/dept.ts`（`createDept`/`updateDept`/`deleteDept`）、`src/api/permission.ts`（`createPermission`/`updatePermission`/`deletePermission`）。
- 新建 `src/pages/dept/DeptList.tsx`（树表 + 上下级选择 + 增删改）、`src/pages/permission/PermissionList.tsx`（分页 + 类型筛选 + CRUD）、`src/pages/job/JobList.tsx`（任务列表 + 执行日志双 Tab + 启停开关 + 立即执行）、`src/pages/file/FileList.tsx`（上传 / 下载 / 删除）。
- `src/router/dynamicRoutes.tsx`：`COMPONENT_MAP` 增 `dept`/`permission`/`job`/`file` 四个契约键，路径式 `system/job/index` 经末段匹配可直接命中。
- `vite.config.ts`：proxy 正则扩为 `^/(auth|user|dept|role|menu|permission|audit|job|file)(/|$)`，覆盖 `/job`、`/file` 两个新前缀。
- 所有写操作按钮按 `sys:dept:*`、`sys:permission:*`、`sys:job:*`、`sys:file:*` 权限码渲染（`AuthButton` / `usePermission`）。

**2. whale-auth 菜单种子**

- `db/init.sql`：`sys_menu` 由 6 条扩至 8 条，新增 id 7「定时任务」`/system/job` `system/job/index`、id 8「文件管理」`/system/file` `system/file/index`。
- 新增 `db/migration-5.34.sql`（`INSERT IGNORE` 幂等），供已部署库补菜单。

**3. 端口占位缺陷修复（5 处）**

- `backend/whale-apps/whale-{erp,mes,oa,pdm}/src/main/resources/application.yml` 与 `backend/whale-registry/whale-config/src/main/resources/application.yml`：`${server.port:9xxx}` → `${SERVER_PORT:9xxx}`。
- 根因同 Wave 5.33 monitor：带 actuator 的服务启动时 `server.port` 自引用触发 `Circular placeholder reference`；改环境变量读取即解除。
