## P2-4 ImBotService#openDefault 并发首建失败修复

### 范围

修复 [Wave 5.55 部署验证](../reviews/2026-10-25-wave5.55-deployment-verification.md) P2-1/B16：并发首建机器人会话偶发 `Duplicate entry '1-B:2' for key 'im_conversation.uk_tenant_pair_key'`，接收人通知丢失。

### 根因

`openDefault` 的 `@Transactional`（REPEATABLE READ）在首次 `findExisting` 建立快照；撞唯一索引后 catch 块在**同一事务**重查仍读旧快照，看不到并发事务已提交的行，误判 null 后 rethrow。

### 变更点

- `ImBotService`：构造器新增 `PlatformTransactionManager`，装配 `recoveryReadTemplate`（`REQUIRES_NEW + READ_COMMITTED`）；catch 块的恢复读（findExisting + ensureMember + ensureBinding）整体包进新事务，跳出外层快照；恢复读仍为 null 则原样 rethrow。
- `ImBotServiceTest`：注入 txManager mock；既有并发恢复用例补事务属性断言（`ArgumentCaptor<TransactionDefinition>`）；新增双线程并发首建用例（`AtomicBoolean` 模拟一胜一撞，双方均拿到会话 VO）。

### 验证

- `mvn -o -pl backend/whale-services/whale-im -am package`（JAVA_HOME=java21）：**BUILD SUCCESS**，139 用例全绿（`ImBotServiceTest` 12/12），Checkstyle 0 违规。

## whale-job 多实例调度失效广播（优先级 5-1）

### 范围

`whale-job` 的调度注册表为进程内状态，多实例部署时任务增删改/启停/依赖调整只影响发起实例，其余实例仍按旧 cron 触发，甚至会触发库中已停止的任务（分布式锁只防重复执行）。本轮补「变更广播」，执行链路、锁、重试、分片与依赖编排行为不变。

### 变更点

- 新增 `job/scheduler/JobScheduleBroadcaster`：Redisson `RTopic` 主题 `job:schedule:invalidate`，消息体 `实例标识|动作|任务ID`（纯文本，避免跨版本序列化差异），动作 `RESCHEDULE` / `CANCEL`；自身回声按实例标识过滤；Redisson 不可用或发布/订阅异常只告警，保留单实例语义。
- `JobScheduler`：`reschedule` / `cancel` 拆为「本地执行 + 广播」，新增 `applyBroadcast` 复用同一本地逻辑且不回播；`init()` 注册消费者。
- 测试：`JobSchedulerTest` / `JobSchedulerChainTest` 构造器补广播器；新增 `JobScheduleBroadcasterTest` 5 用例（降级、消息格式、回声过滤与远端动作、非法消息、关闭注销监听）。

### 验证

- `mvn -o -pl backend/whale-services/whale-job -am package` 通过；whale-job 77 用例、0 失败。
- 双实例实机：A(8082) / B(8098) 同 jar 启动，均订阅主题并注册 `jobId=1/2`；A 停任务 1 → B 收到 `action=CANCEL` 并取消；A 启任务 1 → B 收到 `action=RESCHEDULE` 并按最新 cron 重新注册；A 未收到自身回声；任务状态已复原。
- 环境前置：本地 `bluewhale_job` 缺 `job_dependency` / `job_alert` 与 `job_info`/`job_log` 的 `tenant_id`，按 `db/init.sql` + `migration-5.54` 口径补齐后启动通过（本机数据修复，仓库脚本无改动）。

### 遗留

`whale-auth` 权限缓存的多实例失效广播 / Canal 演进为独立残余，本轮未涉及；Redis 断连窗口漏收消息依赖「下次变更重对齐」。详见 [检查报告](../reviews/2026-10-26-p5-job-schedule-broadcast.md)。
