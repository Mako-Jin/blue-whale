## Wave 5.80 M1B-5：ERP 物料/库存只读契约

### 起因

M1B 全景中 M1B-5 因 ERP 缺少内网只读物料/库存接口而待做。本轮先补 ERP 契约，再接入 PDM 客户端与降级，避免 ERP 故障阻断零件页。

### 落地内容

- **ERP 物料**：`ErpItemService#getByCode` + `GET /erp/internal/item/by-code?code=`；不存在时 `data=null`。
- **ERP 库存**：`StockRepository#listBalancesByItemCode`、`InventoryAppService#stockByItemCode` + `GET /erp/internal/stock/by-code?itemCode=`，按物料编码聚合各仓库数量并补仓库编码/名称，无余额返回 0 与空明细。
- **内网安全**：复用 `/erp/internal/**` 既有 internal-deny 与 `InternalTokenSupport`，未新增网关规则或权限码。
- **PDM 客户端**：`PdmIntErpClient#getItem/getStock` 解析物料与库存信封；PDM 回显优先 `erpItemCode`，未维护时回退零件编码。
- **PDM 回显与降级**：`PdmPartErpService` + `GET /pdm/part/{id}/erp-stock`（`sys:pdm:part:list`）；ERP 异常捕获后返回 `degraded=true`、数量 0、空明细，不抛 500。
- **前端**：零件库新增「ERP 库存」按钮，弹窗展示物料状态、库存合计与仓库明细；降级时顶部告警。
- **文档**：新增 spec/tasks 与评审，M1B 检查报告与全景计划同步更新。

## Wave 5.82 M1B-2b：出差报告未交提醒

### 起因

M1B-2 交付时把“出差报告未交提醒”留作剩余项，员工出差结束超过宽限期仍未提交报告时无人提醒，
行政/HR 也无法主动发现。本轮复用既有审批通知网关补齐该闭环。

### 落地内容

- **查询**：`TripRepository.listReportPendingEndedBefore(deadline, limit)` 仅取 `status=APPROVED`、
  `report_status=PENDING`、`end_date <= deadline`，按结束日期升序并限制批量。
- **应用服务**：`TripReportReminderAppServiceImpl` 逐条投递；接收人优先 `applicant_id`，缺失时用
  `UserDirectoryGateway.findUserIdByUsername` 精确解析；幂等键 `OA_TRIP_REPORT:{tripId}:{截止日}`；
  单条异常仅 warn，不中断批处理。
- **定时任务**：`TripReportReminderJob` 每日按 `whale.oa.trip.report-reminder.cron`（默认 09:00）执行，
  宽限期默认 3 天、批量默认 100，支持开关与负值归一。
- **模板**：whale-message `migration-5.86-oa-m1b-trip-reminder.sql` 新增 `OA_TRIP_REPORT_REMINDER`
  （占位符 `applicant/destination/endDate/businessUrl`，`WHERE NOT EXISTS` 幂等）。
- **配置**：`application.yml` 新增 `whale.oa.trip.report-reminder.enabled/cron/days-after/batch-size`，
  支持环境变量覆盖。
- **文档**：新增 spec/tasks 与检查报告，回填全景 §7.1 与路线图 11.3 状态。
