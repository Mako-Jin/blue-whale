# 2026-11-07 开发日志

## Step 3a：ERP CRP 与工作中心一期（Wave 5.78 M3 剩余）

### 起因

MRP 一期已能完成 BOM 展开与计划订单，但计划结果无法判断「车间做不做得出」：ERP 没有工作中心档案，也没有取 PDM 工艺路线的通道，生产订单更没有工序维度。本批补上「工作中心 → 工艺路线快照 → 产能负荷/排程 → 前端甘特」的最小闭环，并为 3b 的工序报工预留订单工序快照。

### 落地内容

- **PDM 只读契约**：新增 `PdmInternalProcessController`（`/pdm/internal/process/routes`）——`GET /by-part/{partCode}` 取最新已发布（`RELEASED`）路线快照，`GET /{routeNo}/versions/{versionNo}` 取指定版本；快照含 `routeNo/versionNo/partCode/partName/releasedAt` 与 `steps[]`（`stepNo/name/workCenter/standardHours/setupHours`）。不新增表、不改 PDM 工艺模型。
- **数据表**：ERP `V14__mfg_crp.sql` 新建 `erp_mfg_work_center`（编码租户唯一、日产能工时、效率率、工作日、启停）与 `erp_mfg_production_operation`（订单工序快照，`UK(tenant_id, order_id, step_no)`），并给 `erp_mfg_production_order` 追加 `routing_no/routing_version/routing_status`。
- **领域**：`WorkCenter`（编码/名称/产能/效率/工作日校验，`capacityOn = 日产能 × 效率/100`，非工作日 0）；`ProductionOperation`（累计报工、剩余量、超计划拒绝）；`CrpCalculator`（无限负荷按窗口工作日均摊识别超载 + 有限前推逐日占用剩余产能、顺延、窗口末标记 `delayed`；缺工作中心订单排除计数；跨度 > 62 天拒绝）；`RoutingCatalog` 端口。
- **适配与仓储**：`PdmRoutingCatalogImpl`（DiscoveryClient + 内网 token，404 视为无路线，其他失败抛 `ROUTING_FETCH_FAILED`）；工作中心仓储；生产订单仓储新增工序加载、`listActiveForCrp`、`updateRouting`。
- **应用/接口**：工作中心 CRUD（编码冲突 40942、不存在 40443）；`GET /erp/mfg/crp/load`（默认今天起 30 天，可按工作中心过滤）；生产订单建单 best-effort 冻结工艺快照（无路线 `NONE`、PDM 失败 `FAILED`，均不阻断建单），新增 `POST /erp/mfg/production/{id}/routing/sync` 重试（仅 DRAFT/RELEASED 且无报工）。
- **权限/菜单**：`migration-5.78-erp-crp.sql` 幂等登记权限 **545–550**（MRP 预留 545–548 顺延）与菜单 **106 工作中心 / 107 产能负荷**；`tenant_admin / erp_manager / erp_mfg` 全量，`erp_member` 只读 545/549。
- **前端**：`WorkCenterPage`（列表/搜索/状态筛选/新增编辑/删除）、`CrpPage`（日期区间 + 工作中心筛选、负荷表、纯 CSS 甘特条带，延期红色/按期绿色）；`api/mfg.ts` 增补工作中心/CRP/工序类型与函数；`App.tsx` 注册两页与 `/erp/mfg/work-center`、`/erp/mfg/crp` 初始路由。
