## 国际化整改（P2 第五批：DTO 校验文案试点 forum）

- **链路核实**：Spring Boot 4 的 `ValidationAutoConfiguration` 会用 `MessageInterpolatorFactory`
  把容器内 `messageSource` 包装成 `MessageSourceMessageInterpolator` 注入 `LocalValidatorFactoryBean`，
  参数校验时按 `LocaleContextHolder` 当前语言解析 `{validation.xxx}`，**不需要自定义 Validator Bean**。
- **forum 试点**：9 个 DTO、43 处校验注解由中文字面量改为
  `{validation.forum.<领域>.<字段>-<约束>}`，新增 41 键（`@Min`/`@Max` 共用区间键）；
  `messages` / `messages_zh_CN` 与原文逐字一致，`messages_en_US` 为自然英文，三份键集均为 118 键。
- **验证**：新增 `ValidationMessageI18nTest` 2 例（zh-CN 中文原文 / en-US 英文翻译，
  覆盖 Boot 自动配置 + SDK 资源扫描链路）；forum `mvn test` + `checkstyle:check` 通过，
  代码引用键零缺失。
- **注意**：未接入 i18n SDK 且无 `spring.messages` 资源的模块需先补资源包，
  否则校验消息会原样显示 `{validation.xxx}` 占位符。
