### 11. Wave 4 · T4.1 分布式令牌黑名单 ✅（REQ-SEC-002 / REQ-DIST-002）

**范围**：落地 auth logout 的 TODO——登出后 accessToken 立即失效，跨实例共享黑名单

- 新增 [TokenBlacklist.java](../../backend/whale-services/whale-auth/src/main/java/com/bluewhale/auth/security/TokenBlacklist.java)：能力接口，明确「分布式生效 / 自动过期 / 失败降级」三条契约
- 新增 [RedisTokenBlacklist.java](../../backend/whale-services/whale-auth/src/main/java/com/bluewhale/auth/security/RedisTokenBlacklist.java)：键 `auth:token:blacklist:<sha256(token)>`（摘要而非常量原文，避免明文凭据入 keyspace），TTL = token 剩余有效期；Redis 异常时 `add` 告警不抛、`contains` 返回未命中
- 新增 `JwtTokenProvider#getRemainingValiditySeconds` 与 `BEARER_PREFIX` 常量（消除过滤器/服务两处重复定义）
- 改造 [JwtAuthenticationFilter.java](../../backend/whale-services/whale-auth/src/main/java/com/bluewhale/auth/security/JwtAuthenticationFilter.java)：抽出 `authenticate`，命中黑名单即保持未认证（嵌套由 5 层降为 2 层）
- 改造 `AuthService#logout(String)` / `AuthController#logout`：从 `Authorization` 头取 token
- `whale-auth/pom.xml` 增加 `spring-boot-starter-data-redis`（`StringRedisTemplate` 懒连接，Redis 缺失时不阻断启动）

**验证**：`mvn -pl backend/whale-services/whale-auth -am compile` → **BUILD SUCCESS**（6 模块 / 67 源文件）

**遗留**：① refreshToken 未纳入黑名单（REQ-SEC-004，P1 残余）；② 网关侧未校验黑名单（REQ-SEC-003，P2）；③ 无 Redis 实机，端到端登出验证待中间件就绪
