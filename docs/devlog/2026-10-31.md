### G1：`whale-file` HTTP Range（M2 前置）

- 下载 / 预览 / 内网内容三个端点统一支持单段 Range：无 Range → 200 全量；可满足 → 206 + `Content-Range`；越界 → 416 + `Content-Range: bytes */size`；多段 / 非法语法按 RFC 9110 忽略。全部响应声明 `Accept-Ranges: bytes`，以 MD5 生成强 `ETag`，`If-Range` 不匹配时回落全量。
- 分层落点：`StoragePlugin` 默认区间读取（`skipNBytes` + `LimitedInputStream`）、`FileStorage` / `StoragePluginRegistry` 端口与委派、MinIO 插件 `GetObjectArgs.offset/length` 原生分段、`FileInfoService#openContent` 区间重载、接口层新增 `FileContentResponses` 收敛响应头与解析逻辑。
- 验证：file 模块 9 个子模块 `mvn test` 全绿（domain 14 / infrastructure 30 / application 36 / interfaces 21 / plugins-local 7 / plugins-minio 7 / architecture-test 4），Checkstyle 0 违规。
