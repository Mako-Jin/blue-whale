# 2026-10-31 开发日志

## 需求

- 启动 **Wave 5.75 音乐平台 `whale-music`**：新建核心服务（8096 / `/music/**` / `bluewhale_music`），对标网易云 / QQ 音乐的租户内音乐平台，覆盖曲库、播放、歌单、发现、评论与运营台。
- 产品口径确认：**所有人可上传**；上传前必须签署《版权无争议协议》并记录协议版本；歌曲可见性可选择**公开（租户内）**或**自听（仅本人）**；公开作品不设上传前置审核，运营事后复核并可下架。
- 本阶段范围：**M0 设计与骨架**（M0-1 至 M0-6），不涉及曲库业务与前端页面。
