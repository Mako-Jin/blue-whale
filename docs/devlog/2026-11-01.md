# 2026-11-01 开发日志

## 需求

- 依据 [安全基线四项核查与实施计划](../plans/2026-10-31-security-baseline-config-flyway-password-rotation.md) 按「阶段 0 → 1 → 3 → 2 → 4」顺序实施，并追加四项口径：
  1. 租户口令策略：口令有效期/提醒天数由租户管理员自助配置；
  2. 管理员重置口令：系统生成一次性临时口令，明文仅在响应/结果弹窗展示一次；
  3. 中间件账号（MySQL/Redis/RabbitMQ/Nacos）暂不纳入自动定期改密；
  4. 恢复既有任务，继续执行。

## 完成

### Jasypt 配置加密（REQ-SEC-020）

- 新增 `whale-common/whale-config-crypto`：`ConfigEncryptionEnvironmentPostProcessor`（`META-INF/spring.factories`）+ `ConfigEncryptionSettings` + `ConfigValueCipher` + `EncryptedPropertySource` / `EncryptedEnumerablePropertySource` + `ConfigEncryptionTool`；算法 `PBEWithHMACSHA512AndAES_256`，密文 `ENC(...)`，密钥 `WHALE_CONFIG_ENC_KEY`（≥16 字符）。
- 启动守卫：存在密文但缺密钥、密钥过短、密钥为占位值均 fail-fast；工具 `scripts/security/encrypt-secret.ps1`；`.env.example` 增加密钥与轮换说明。
- **完整性哨兵**：Jasypt PBE 无认证性，错密钥解密可能静默返回乱码。`ConfigValueCipher` 在明文中前置 `whale-enc:`，解密后校验标记，缺失即抛「完整性校验失败」，让错密钥稳定失败。

### 口令策略与定期改密（REQ-SEC-021 / REQ-SEC-023）

- BCrypt `strength=12` + 登录自动升级；`PasswordPolicy` / `PasswordPolicyProperties` 统一强度（12–64 位、四类字符、不得含用户名、常见弱口令）；`PasswordPolicyService` 负责强度校验、历史复用校验、加密与历史落库（最近 5 次）。
- `User` 聚合新增 `passwordUpdatedTime`、`isPasswordExpired`、`passwordExpiresInDays`、`changePassword(EncryptedPassword, changedAt)`；`sys_user` 增 `password_updated_time` / `password_notice_time`，新建 `sys_password_history`（`migration-2026-11-01-password-lifecycle.sql` 幂等，存量回填 `create_time`）。
- 自助改密 `PUT /auth/password`（`PasswordAppService`）：校验旧口令 → 强度/历史校验 → 改密 → 清强制改密 → 发布 `PASSWORD_CHANGED` 撤销存量令牌；`@AuditLog(recordParams=false)` 不记录口令。
- 登录/刷新响应透出 `mustChangePassword`（强制改密或已到期均折算）、`passwordExpired`、`passwordExpiresInDays`；JWT 声明 `pwdChangeRequired`。
- 双层阻断：网关 `JwtAuthGlobalFilter` 与 auth `JwtAuthenticationFilter` 对非白名单路由返回 403 `PASSWORD_CHANGE_REQUIRED`；白名单 `/auth/password`、`/auth/logout`、`/auth/refresh`、`/auth/me`。
- 到期提醒 `PasswordExpiryNoticeJob`（默认每日 02:00）：按租户策略取最短窗口一次跨租户扫描，再按候选账号租户二次筛选；`password_notice_time` 保证同一口令周期只提醒一次。
