## 四、已修正问题项

| 问题 | 根因 | 修正 |
| --- | --- | --- |
| 权限迁移在真实库执行失败（`Unknown column 'tenant_id'`） | 误按租户表结构写 `sys_permission`，基线 V1 中该表无 `tenant_id` | 删除插入列与对应值，按 `perm_code` 幂等 upsert |
| 权限迁移执行失败（`Data too long for column 'method'`） | `GET/POST/PUT/DELETE`、`GET,POST,PUT,DELETE` 超过 `VARCHAR(16)` | 统一写 `ALL` |
| OA 文档模块建表失败（`separator` 语法错误） | 列名与 MySQL 保留字冲突 | DDL/种子 SQL 加反引号，实体加 `@TableField("`separator`")` |
| ERP 生产订单下达推送异常 | Spring 7 对 `@TransactionalEventListener` 事务传播的硬约束 | 改为 `REQUIRES_NEW`，推送与回写使用独立事务 |
| crm/erp/oa/pay 启动缺 `ObjectMapper` Bean | Boot 4 默认 Jackson 3，不再注册 Jackson 2 Bean | 新增 `Jackson2CompatConfig`（`@ConditionalOnMissingBean`） |
| 本地服务连不上 Redis | compose 开启 `requirepass`，服务端 `spring.data.redis` 未配密码 | 本地开发关闭密码；生产改用环境变量注入 |
