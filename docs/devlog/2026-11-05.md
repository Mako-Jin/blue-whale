## Wave 5.78 M2 剩余 B 第六期：ERP 信用在途预占

### 起因

现有信用校验只比对「未结应收 + 本单金额」，多张订单在发货前同时审核时互相不可见，可能合计超额度而不被拦截。本片把「已审核未发货」金额纳入占用，发货转应收时同步释放。

### 口径（D8 暂定）

- 信用占用 = 未结应收 + 在途预占。
- 在途预占 = `APPROVED` / `PARTIALLY_SHIPPED` 订单的（订单总额 − 已发货金额）；`DRAFT` / `CANCELLED` / `SHIPPED` / `CLOSED` 不计入。
- 审核校验：占用 + 本单金额 ≤ 额度；发货校验：占用 ≤ 额度（预占已含本单未发货额，发货后同额转入应收，避免重复占用）。
- 额度 0 仍视为不限，与既有规则一致。

### 落地内容

- 仓储：`SalesOrderRepository#reservedAmount(customerId)`，按客户汇总在途订单未发货金额，空值按 0 处理。
- 应用：`SalesAppServiceImpl` 审核改为「未结应收 + 在途预占 + 本单金额」，发货改为「未结应收 + 在途预占」，错误信息输出占用与预占明细。
- 不新增表、端点、权限与前端页面。

### 验证

- `.\mvnw.cmd -pl :whale-erp "-Pcoverage-gate" verify`：**BUILD SUCCESS，464 tests，0 failures**，覆盖率达标，Checkstyle 与 ArchUnit 通过；`SalesAppServiceImplTest` 10 项全绿（本片新增 3 项）。
- 文档一致性 `DOC-CONSISTENCY-PASS`；部署契约 `RESULT: PASSED`。
- 检查报告：[2026-11-05-wave5.78-erp-m2-credit-reservation.md](../reviews/2026-11-05-wave5.78-erp-m2-credit-reservation.md)。
