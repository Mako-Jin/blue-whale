# 开发日志 2026-11-05

## Wave 5.78 M2 剩余 B 第二期：ERP 采购申请 + 销售报价

### 起因

上一期（采购退货 + 销售退货）已提交后，继续推进 ERP 全景计划 M2 剩余 B：订单前置的采购申请与销售报价缺失，业务只能直接建订单。用户指令「继续处理，完成之后提交代码」。

### 落地内容

- **迁移**：`V10__scm_requisition_quotation.sql` 4 张表（采购申请头/行、销售报价头/行），唯一键 `uk_pa_doc_no`/`uk_pa_line`/`uk_sq_doc_no`/`uk_sq_line`；仅 `CREATE TABLE IF NOT EXISTS`，无物理外键。
- **领域**：`PurchaseRequisition(+Line)`、`SalesQuotation(+Line)`；`ScmStatus` 补 `ACCEPTED`/`CONVERTED`。行金额 2 位 HALF_UP，头金额为行合计；数量与单价必须为正。
- **状态机**：采购申请 `DRAFT → APPROVED → CONVERTED`，销售报价 `DRAFT → ACCEPTED → CONVERTED`；`CONVERTED` 拒绝取消。
- **应用服务**：建单取供应商/客户/物料启用快照；转单复用 `PurchaseAppService.create` / `SalesAppService.create` 生成草稿订单，回写 `convertedOrderNo` 并置 `CONVERTED`，重复转单拒绝。
- **单号**：`PA-yyyyMMdd-%04d`、`SQ-yyyyMMdd-%04d`。
- **接口**：`/erp/scm/purchase-requisition`、`/erp/scm/sales-quotation` 各 6 端点（分页/详情/建单/审核或接受/转单/取消）。
- **权限/菜单**：权限 515–526、菜单 100–101；复用角色 `erp_scm`，`erp_member` 仅查询。
- **前端**：`api/scm.ts` 12 个函数；采购申请页、销售报价页（列表 + 状态筛选 + 新建弹窗 + 详情 + 审核或接受 + 转单 + 取消）；基座 `/erp` 菜单补两项。
- **测试**：领域 2 组 + 应用服务 2 组 + 迁移 V10 断言；迁移测试脚本排序改为按版本号升序（避免 `V10` 排在 `V1` 前）。
- **文档**：计划 §12.6、设计 §3.2 与变更记录 v1.0、检查报告、service-catalog、register。
