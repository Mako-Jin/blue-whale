# 开发日志 2026-10-24

## 一、基座真实登录 + proxy 补齐（Top 1：解除前端联调阻塞）

- 背景：`whale-platform`（基座，8000）登录仍为本地 mock（`admin/123456` + 伪造 JWT），子应用拿不到真实令牌；且 `vite.config.ts` 无网关 proxy，所有 API 请求 404。
- 交付（`frontend/platform-apps/whale-platform`）：
  - 新增 `src/api/token.ts`：登录态唯一读写入口，键名 `whale_platform_access_token` / `whale_platform_refresh_token` / `whale_platform_user`，与 admin（`whale_token`）隔离，避免串号；提供 `useCurrentUser` + `subscribeCurrentUser`，主布局可响应 `/auth/me` 结果。
  - 新增 `src/api/client.ts`：`createHttpClient<LoginResponse>` 接入 `@bluewhale/http`，注入 token/refresh/clearAuth，复用 401 单飞续期；导出 `http/get/post/put/del/refreshSession`。
  - 重写 `src/api/auth.ts`：
    - `login` → `POST /auth/login`，成功落盘 access/refresh token，并发 `AUTH_LOGIN` 审计事件；
    - `fetchMe` → `GET /auth/me`，合并 `permissions/menus` 到本地用户态，权限集变化发 `AUTH_PERMISSION_CHANGE`；
    - `logout` → `POST /auth/logout`（带 refreshToken），服务端异常不阻断本地清态，先发 `AUTH_LOGOUT` 再 `clearAuth`。
  - `src/pages/login/index.tsx`：登录成功后调用 `fetchMe()`（失败仅告警不阻断登录）；提示文案改为真实接口口径。
  - `src/layouts/MainLayout.tsx`：昵称改用 `useCurrentUser()`；退出改为 `await logout()` 后跳转。
  - `vite.config.ts`：20 个网关一级前缀（`/auth /user /dept /role /menu /permission /erp /mes /pdm /oa /workflow /form /file /alert /monitor /audit /agent /job /pay /config`）转发到 `http://127.0.0.1:8080`；对 `GET` 且 `Accept: text/html` 的文档导航旁路，避免吞掉 qiankun 的 `/erp`、`/oa`、`/mes`、`/pdm` 浏览器路由。
  - `package.json`：新增 `@bluewhale/http: workspace:*`（`pnpm-lock.yaml` 同步更新）。
- 验证：`pnpm --filter @bluewhale/whale-platform... build` EXIT=0（先构建 6 个 workspace 依赖，基座 `tsc -b && vite build` 3901 modules / 8.55s）；`lint` EXIT=0（仅 `MODULE_TYPELESS_PACKAGE_JSON` 环境提示，无 ESLint 告警）。

## 二、whale-tools / whale-security 底层缺口补齐（Top 5）

- `whale-tools`：
  - `StringUtils` 重写：`isBlank/isNotBlank/isEmpty/isNotEmpty/defaultIfBlank/trimToNull`，统一委托 hutool `StrUtil`，避免自实现边界差异。
  - `DateUtils` 重写：缓存 `yyyy-MM-dd` / `yyyy-MM-dd HH:mm:ss` 两个 `DateTimeFormatter`，提供 `now/today/formatDate/formatDateTime/parseDate/parseDateTime/format/parse/startOfDay/endOfDay`。
  - `pom.xml` 补 `junit-jupiter` 测试依赖；新增 `StringUtilsTest`（6 用例）、`DateUtilsTest`（6 用例）。
- `whale-security`：
  - `JwtUtils`：jjwt 0.12.5 新 API，HS 密钥 UTF-8 字节 ≥32（`MIN_SECRET_BYTES`），`generateToken/parseToken/validateToken/refreshToken`；续签时剔除 `iat/exp/nbf` 后重签。
  - `AesCrypto`：`AES/GCM/NoPadding`，12 字节随机 IV + 128 位 tag，输出 `IV||密文` 后 Base64；密钥仅接受 16/24/32 字节。
  - `RsaCrypto`：2048 位密钥对（小于 2048 拒绝），`OAEPWithSHA-256AndMGF1Padding` 加解密，`SHA256withRSA` 签名验签，X.509 / PKCS#8 + Base64 密钥序列化。
  - `Sm4Crypto`：本机离线仓库无 BouncyCastle，改为**纯 JDK** 实现 SM4 轮函数 + CBC + PKCS#7；S 盒以十六进制串静态构建、CK 按标准公式生成；加密前置 16 字节随机 IV，解密去填充后以同 IV 重加密比对做完整性校验。
  - 新增 4 个测试类共 28 用例（JWT 8 / AES 7 / RSA 6 / SM4 7），其中 SM4 使用 GB/T 32907 标准向量（`0123456789abcdeffedcba9876543210` → `681edf34d206965e86b3e94f536e4246`）。
- 验证：`mvn -o -f backend/pom.xml -pl :whale-tools,:whale-security -am test` → **BUILD SUCCESS**；`whale-tools` 12 用例、`whale-security` 34 用例全绿；两模块 Checkstyle（`checkstyle-gate`）均为 **0 violations**。

## 四、遗留与说明

- `JwtUtils` / `AesCrypto` / `RsaCrypto` / `Sm4Crypto` 当前**无业务调用点**（实测仅自引用），本次作为公共能力底座补齐；`whale-auth` 仍使用既有 `JwtTokenProvider` 链路，未受影响。
- SM4 采用纯 JDK 实现而非 BouncyCastle，性能与侧信道防护弱于成熟密码库；生产接入国密合规场景时应替换为 `bcprov` 或硬件密码机，本次仅保证标准向量正确。
- 基座构建存在既有产物 `index-*.js` 1,050 kB（>500 kB）体积告警，与本次改动无关，留待后续手动分包。
- 本机 `node`/`pnpm` 直接调用报 `sandbox backend failed`，验证统一改用 `Start-Process D:\nodejs\node.exe + pnpm.cjs` 绕过。

## 五、前端 console 统一替换为工具类 Logger

- 检查结论：`@bluewhale/whale-common-tools` 已提供 Logger（分级 `trace/debug/info/success/warn/error`、命名空间、CSS/ANSI/plain 渲染、`onRecord` 结构化记录），且 `initAuditLogging()` 会把 Logger 记录接入通道③ `frontend_log` 并写到劫持前的原生 console；但**应用代码仍有 4 处直接调用 console**，此前未完成替换。
- 替换清单：

  | 文件 | 原调用 | 现调用 |
  |---|---|---|
  | `whale-platform/src/qiankun/index.ts:30` | `console.error('[qiankun] 子应用加载失败', ...)` | `logger.error('子应用 ${name} 加载失败', message)` |
  | `whale-platform/src/qiankun/index.ts:46` | `console.error('[qiankun] global error:', event)` | `logger.error('qiankun global error', event)` |
  | `whale-portal/src/api/workflow.ts:82` | `console.warn('[whale-portal] 查询待办任务失败', error)` | `logger.warn('查询待办任务失败，返回空列表', error)` |
  | `whale-portal/src/pages/Todo.tsx:62` | `console.warn('[whale-portal] 「去处理」为占位实现')` | `logger.warn('「去处理」为占位实现')` |

  命名空间分别为 `whale-platform › qiankun`、`whale-portal › workflow`、`whale-portal › todo`；原 `[whale-portal]` 文本前缀由命名空间承担，避免双重前缀。
- 刻意保留（不属应用日志）：`whale-log-sdk/src/console.ts`（console 劫持实现）、`whale-common-tools/src/logger/logger.ts`（Logger 原生输出通道）、`shared-packages/*/scripts/*.mjs`（Node 冒烟脚本）。
- 验证：应用 `src/**/*.{ts,tsx}` 检索 `console.(log|info|warn|error|...)` 为 0 命中（仅 Logger 实现注释中提及）；`whale-platform` 与 `whale-portal` 的 `lint`、`build` 均 EXIT=0。
