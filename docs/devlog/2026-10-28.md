## 6. CRM / SRM 边界结论

- **供应商管理 ≠ CRM**：CRM 的核心对象是客户、联系人、商机、销售漏斗；供应商准入、资质、询比价、绩效、风险属于 **SRM/采购/供应链**，或 ERP 的供应商主数据。
- 本期**不新增 `whale-crm`**；合同域继续维护「相对方」快照，电子签渠道配置留在合同域。
- 若采购流程复杂度上升，另立 `whale-srm`；只有在客户/商机管理成为真实需求时才立项 `whale-crm`。

## 16. GitHub Actions 触发条件核对（V-08 前置）

四条 workflow 触发矩阵（`.github/workflows/`）：

| 文件 | 触发条件 | 本次（docs 提交）是否触发 |
|---|---|---|
| `backend-ci.yml` | `push`/`PR` main，paths `backend/**`、`pom.xml`、本文件 | 否（仅改 docs） |
| `frontend-ci.yml` | `push`/`PR` main，paths `frontend/**`、`pnpm-workspace.yaml`、`package.json`、本文件 | 否 |
| `code-quality.yml` | `push`/`PR` main，paths `backend/**`、`frontend/**`、`ai/**`、`config/checkstyle/**`、本文件 | 否 |
| `docker-deploy.yml` | **仅** `push tag v*.*.*` 与 `workflow_dispatch` | **否**（main push 永不产出镜像） |

核对结论：

1. **`push main` 不会构建镜像**：`docker-deploy.yml` 无 branch 触发，前三轮 `main` 推送（含 5.68–5.73 服务新增）均未触发镜像流水线；V-08 不可能被日常推送"顺带"覆盖。
2. **无任何语义化 tag**：本地与 GitHub 侧仅有 `legacy-github-main-20261023`，`v*.*.*` 触发器自建立以来从未命中。
3. **`GITHUB_TOKEN` 足够**：workflow 已声明 `permissions: packages: write`，GHCR 登录复用 `GITHUB_TOKEN`；原待办"需 registry 凭据"口径不准确，真实阻塞在 tag/dispatch 与仓网络。
4. **`image_tag` 输入是死参数**：`workflow_dispatch` 声明了 `image_tag`，但 `docker/metadata-action` 的 `tags` 只含 `type=ref,event=tag` 与 `type=sha`，手动触发只能得到 `sha-xxxxxxx`，无法指定版本号。
5. **Actions 实际运行仓是 `ci`**（`Mako-Jin/blue-whale-platform`，见 `cicd.md` §6.3）；本次 `git push ci main`、`git fetch ci` 全部失败（`HTTP/2 stream not closed`、`443` 超时，切 HTTP/1.1 同样超时），`ci/main` 仍停在 `75baa0c`（落后 165 提交，可快进）。`github` 仓（`Mako-Jin/blue-whale`）匿名 API 返回 404（私有），无法确认其 Actions 开关状态。
6. **后端矩阵 20 项路径逐一 `Test-Path` 核对全部存在**；`deploy/backend/sample/Dockerfile` 仅 COPY `.mvn`、`config/checkstyle`、`backend`，而 `backend/pom.xml` 无 `parent`（聚合根在仓库根 `pom.xml`），故 `mvn -f backend/pom.xml -pl ... -am` 在镜像内自洽；`.mvn/jvm.config` 仅 `-Xmx2g`，随镜像无副作用。
7. **覆盖缺口（新增 V-15）**：矩阵缺 `whale-apps/whale-contract`（`SERVER_PORT` 9006、网关 `lb://whale-contract` 已启用）；前端仅构建 `whale-web`（`frontend/admin` → 包名 `whale-admin`，`APP_NAME`/`APP_DIR` 默认值与实际一致），`whale-portal`、erp/oa/mes/pdm/pm/contract 子应用（contract 8109）、form-designer(8002)、workflow-designer(8003)、ops 均无镜像。
8. **成本提示**：20 个后端 job 各自 `-am package`，`whale-common`/SDK 等共享模块被重复构建 20 次；首次无 GHA 缓存时预计显著长于本机构建，免费额度并发上限 20 个 job，矩阵已达 21（含前端），会排队。
