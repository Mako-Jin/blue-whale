### 6. Wave 2：核心服务 3 路并行任务 ✅

**范围**：whale-auth 权限中心 / whale-gateway 网关 / whale-i18n-sdk 国际化，依赖 Wave 1 契约并行完成

- T2.1 whale-auth（端口 8081）：jjwt 0.12 API（HS256，claims sub/userId/roles）+ Spring Security 7 SecurityFilterChain 无状态链 + JwtAuthenticationFilter + UserDetailsService（DB 联查）；RBAC 六层级全套——8 实体/8 Mapper/13 DTO/7 VO/6 组 Service/6 Controller（/auth/login|refresh|logout、user/role/menu/permission/dept CRUD+树）；@RequirePermission 注解 + 拦截器（super_admin 直通 → authorities → 兜底查 DB）；密码经 VO 层隐藏；关联表物理删除避免逻辑删与唯一键冲突；admin 种子数据在 init.sql
- T2.2 whale-gateway（端口 8080）：Gateway 5.x（`spring-cloud-starter-gateway-server-webflux`）+ Nacos 8 条 lb 路由（统一 StripPrefix=1）+ 白名单（AntPathMatcher 配置化）+ JwtAuthGlobalFilter(-100)（Bearer 校验，注入 X-User-Id/X-Username/X-User-Roles，先移除伪造头）+ TraceIdGlobalFilter(-200)（X-Trace-Id 透传+响应头）+ ErrorWebExceptionHandler(-2)（404/500 Result JSON）；未依赖 whale-spring-boot-starter（WebFlux 自包含）
- T2.3 whale-i18n-sdk：WhaleMessageSource 三级回退（DB→Redis 缓存→属性文件→默认值→code 本身，三重载永不抛异常）+ StringRedisTemplate 缓存（TTL 可配、空哨兵防穿透、断连降级限流告警）+ DbI18nDatabaseProvider SPI 实现（@ConditionalOnBean(DataSource)）+ 自动装配条件矩阵（无 MyBatis/Redis 时优雅退化）

**跨模块约定对齐**：JWT 密钥 `bluewhale-jwt-secret-2026-please-change-in-production`（auth/gateway 一字不差）；authorities 为角色 code 原样无 ROLE_ 前缀；网关注入 Header 与 auth Token claims 对应

**验证**：T2.1/T2.2 `mvn -pl ... -am compile` BUILD SUCCESS；T2.3 `mvn -pl whale-sdk/whale-i18n-sdk -am test` 14 用例全绿（含 Redis 断连降级、防穿透、Resolvable 重载）
