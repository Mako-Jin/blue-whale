## 三、规则复核

- 迁移仅新增表与幂等加列，无 `DROP/TRUNCATE/DELETE`，无物理外键，种子 `NOT EXISTS` 幂等。
- ArchUnit：`approval → hr` 无反向依赖，事件类在 `approval`、监听器在 `hr`；视图不引用 entity。
- 额度不变量：`used + frozen ≤ total`（`allowNegative` 例外）；所有变动写流水并记录前后快照。
- 幂等：重复同步同一终态不重复扣减；重复 upsert 档案/日历/额度初始化不产生重复行。
- 权限：普通员工无 `:edit` 权限；跨租户按租户插件隔离。
