### 待做项

4. 通知模板可配置化（当前标题与文案内置在代码）。

### 已修正问题项

1. **异步丢失租户上下文**：`@Async` 线程不继承 `ThreadLocal` → 线程池挂载 `TenantContextTaskDecorator`，事件发布时捕获 `tenantId`，投递后 `clear()`。
2. **关闭态仍有构造开销**：初稿无论开关都构建事件 → 改为 `enabled` 判定前置返回，保证零副作用。
3. **机器人消息复用用户发送路径**：会伪造客户端请求并触发内容校验分支 → 抽出通用 `buildMessage`，新增 `sendAsBot` 指定发送者与内容类型。
4. **评论通知漏掉被回复人**：初稿仅通知负责人 → 补充父评论作者，发布器统一去重并过滤操作人本人。
5. **IM 内部接口越权风险**：内网接口若可经网关访问等同绕过权限 → 网关 `internal-deny` 增加 `/im/internal/**`，外部 403。
