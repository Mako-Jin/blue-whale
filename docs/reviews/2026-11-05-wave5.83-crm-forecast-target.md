## 2. 关键口径

- **预测四项**：管道 = 未关闭商机金额（CONTACT / PROPOSAL / NEGOTIATION）；最佳 = NEGOTIATION；承诺 = WON + 概率 ≥ 90 的未关闭商机；加权 = Σ 金额 × 概率 / 100（WON 按全额）；`opportunityCount` 为未关闭商机数。金额两位 HALF_UP。
- **周期**：月 `yyyy-MM`、季 `yyyy-Qn`，非法格式抛 `FORECAST_PERIOD_INVALID`；季周期起止为季度首末日。
- **范围**：USER 写 `owner_id` 且 `dept_id=0`；DEPT 写 `dept_id` 且 `owner_id=0`；唯一键 `(tenant_id, period_type, period, scope_type, owner_id, dept_id)`。
- **重新生成**：同周期同范围 upsert 覆盖四项金额与商机数，并置 `manualAdjusted=false`；手工调整写 `crm_forecast_adjustment` 前后值并置 `manualAdjusted=true`。
- **目标完成率** = 同期赢单商机金额 ÷ 目标金额 × 100（两位 HALF_UP）；金额变化必须填原因，写 `crm_sales_target_adjustment`。
- **数据范围**：`actor.allDataScope()` 可跨人 / 部门；否则强制本人 `owner_id` 并清空 `deptId`；跨租户或他人资源一律按不存在处理。
- **并发**：快照与目标均带 `@Version`，更新失败抛「已被他人修改，请刷新后重试」。
