## 2. 关键口径

1. **唯一性**：同一租户内「价格类型 + 往来方 + 物料」唯一；新建先查重，命中抛 `PRICE_LIST_CONFLICT(40940)`。
2. **合法性**：单价必须大于 0（`PRICE_INVALID`）；有效期止不得早于起（`DOC_DATE_INVALID`）；有效期为空表示不限。
3. **取价**：只认 `ENABLED` 且有效期覆盖业务日期的记录；未命中抛 `PRICE_LIST_NOT_FOUND(40440)`；`/resolve` 日期缺省取当天。
4. **建单兜底**：销售订单与销售报价按 `SALES + 客户`、采购订单按 `PURCHASE + 供应商` 取价；显式传入单价时以单据为准，不做价格偏离校验。
5. **状态**：启停复用 `ScmStatus.ENABLED/DISABLED`，避免 SCM 领域反向依赖主数据包；启停为独立端点，更新接口不允许改价格类型与往来方。
6. **主数据**：客户走 `CustomerRepository`，供应商/物料走 `SupplierCatalog` / `ItemCatalog` 端口；停用主数据拒绝建价。
