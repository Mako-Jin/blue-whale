## 三、A 类 —— 协议与接口安全

| 检查项 | 结论 |
|---|---|
| 越权访问 | 7 个端点分别标注 `sys:archive:item:list/read/edit/archive/destroy/download`，与权限种子 144–150 对齐 |
| 下载鉴权 | 先按 `archive_item` 存在性校验，再校验 `archive_file.item_id == 路径 id`，跨条目文件返回 `NOT_FOUND`；文件二进制经内网 `/file/internal/{id}/content` 获取，不经外部直链 |
| 响应头安全 | 下载响应显式 `X-Content-Type-Options: nosniff`，`Content-Disposition` 同时给出 ASCII 兜底名与 RFC 5987 编码名 |
| SQL 注入 | 全部查询使用 `LambdaQueryWrapper` / `QueryWrapper` 参数绑定；统计 `groupBy` 列名由服务内固定常量传入，无外部拼接 |
| 输入校验 | 整理请求用 Jakarta Validation（门类必填、密级 1–3、期限 1–100、摘要/关键词长度），服务层二次归一化与长度校验 |
| 参数边界 | 分页 `size` 收敛 `[1,200]`、`current >= 1`；年度仅允许 1900–9999（前端约束 + 后端 `year` 取自条目） |
| 错误信息 | 统一 `BizException` + `ErrorCode`，不暴露 SQL/堆栈；来源状态读取失败仅告警并按 `null` 返回 |
| 审计 | 整理/确认/销毁/下载均 `@AuditLog`，`targetType=archive_item`、`targetId=#id` |

## 四、B 类 —— 代码漏洞与健壮性

| 检查项 | 结论 |
|---|---|
| 并发确认 | `confirm` 用 `update ... where id=? and item_status=0` 条件更新，行数为 0 时回读判定是否已被他处归档，避免重复取号与档号冲突；档号分配仍走 M1 的数据库原子自增 |
| 幂等 | 已归档重复确认直接返回既有档号；已销毁重复销毁直接返回；整理仅允许 `item_status=0` |
| 事务边界 | 整理、确认、销毁均 `@Transactional(rollbackFor = Exception.class)`；无自调用 |
| 状态一致性 | 编辑门类时同步重算 `category_path`；修改保管期限且来源办结时间存在时重算 `expire_at` |
| 外部依赖降级 | `sourceStatus` 读取工作流失败仅 `warn`，不阻断详情；文件下载 404 转 `NOT_FOUND` |
| 前端安全 | 无 `dangerouslySetInnerHTML`；无 `console` 直调；下载 anchor 使用 `URL.revokeObjectURL` 回收 |
| 敏感信息 | 下载日志不记录文件内容；前端不缓存 token，统一复用 `api/token.ts` |

## 五、C 类 —— 圈复杂度与结构

- 分支最多的 `ArchiveItemService#page`（5 个可选条件）与 `#edit`（6 个可空字段）均为线性条件，复杂度 < 10。
- `ArchiveItemController` 仅做参数接收、权限/审计声明与响应封装；下载仅做 MIME 解析与响应头拼装。
- 分层仍为 Controller → Service → Mapper；前端页面与 API 分离，无跨页耦合（公共常量集中在 `pages/archive/helpers.ts`）。

## 六、D 类 —— 魔法值

- 分页上限、标题/摘要/关键词长度、下载兜底名与 MIME、统计别名、未知分组占位全部收敛为具名常量。
- 条目状态、来源类型、密级复用 `ArchiveConstants`；前端密级/状态/文件角色映射集中在 `helpers.ts`。

## 七、E 类 —— 命名、格式与工程规范

| 项 | 结论 |
|---|---|
| 命名 | 后端沿用 `com.bluewhale.archive.*`；前端 `pages/archive`、`api/archive.ts` 与菜单契约键一致 |
| Javadoc | 新增类型与全部方法（含 private）均有中文 Javadoc，Checkstyle 0 违规 |
| 格式 | 4 空格缩进；新增文件无 >120 字符行；无未使用 import（ESLint `--max-warnings 0` 通过） |
