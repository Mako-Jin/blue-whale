## 3. 关键规则与不变量

| 规则 | 实现 |
|---|---|
| 主体匹配 | `ALL` 恒命中；`USER` 比较用户 ID 文本；`ROLE` 比较网关下发的角色 code；其他主体不命中 |
| 继承范围 | 文档规则 + 文档所在目录及全部父目录的目录规则；目录规则对子孙目录内文档生效 |
| DENY 优先 | 命中规则中任意 `DENY` 即拒绝，`ALLOW` 无法覆盖 |
| 无规则回落 | `ABSTAIN`：读放行（仍受功能权限码约束）、写回落属主/管理员 |
| 列表过滤 | 仅收敛 `VIEW + DENY` 目录子树与文档；空集合不追加 SQL 条件 |
| MANAGE 鉴权 | `DENY` 拒绝、`ALLOW` 放行、`ABSTAIN` 要求属主或 `pdm_manager`/`pdm_doc_manager`/`tenant_admin` |
| 唯一键幂等 | `PUT /pdm/acl` 唯一键重复时返回既有规则；并发冲突捕获 `DuplicateKeyException` 后重查 |
| 租户隔离 | 复用 MyBatis 租户行插件；跨租户资源按 ID 查询返回 404 语义 |
| 审计 | ACL 新增/删除记录 `@AuditLog`，不记录规则细节以外的敏感内容 |

## 5. 风险与遗留

| 风险 | 影响 | 处置 |
|---|---|---|
| `subject_id` 类型变更 | 存量 `BIGINT` 数据需转字符串 | 迁移仅在 `bigint` 时执行，数值文本兼容；上线前备份 `pdm_doc_acl` |
| ACL 误配导致全员不可见 | 目录 `DENY` 会隐藏子树内全部文档 | 管理端删除 `DENY` 规则即可恢复；`ALLOW` 不会突破 `DENY` |
| 目录树未裁剪 | 被 `DENY` 的目录名仍可见 | 文档列表/详情/下载已隔离；目录树可见性裁剪留待 M1A 权限细化 |
| 下载无短时票据 | 依赖登录态 + 功能权限 + ACL | 后续引入短时票据，绑定用户/文档/版本 |
| 预览/导出缺失 | 无法在线查看 DWG/PDF | 后续按计划实现预览任务与导出 |
| DEPT 主体缺失 | 无法按部门授权 | 网关暂不下发部门头；待身份头补齐后扩展 |
