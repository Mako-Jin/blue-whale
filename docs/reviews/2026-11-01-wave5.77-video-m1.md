## 2. 关键实现口径

### 2.1 内容聚合与状态机

- 发布状态 `DRAFT / PENDING_REVIEW / PUBLISHED / OFFLINE`；版权状态 `AUTHORIZED / TAKEDOWN`。
- `publish(maxDurationMs)` 前置条件：版权未下架、标题非空且 ≤200、`videoFileId > 0`、`durationMs > 0` 且不超类型上限、授权未过期；**已发布重复调用幂等**（仅刷新 `publishedAt`）。
- `offline()`：草稿 / 待审拒绝（`40901`），重复下架幂等。
- `takedown(reason)`：强制 `OFFLINE` + `TAKEDOWN`、原因 trim 落 `takedownReason` / `takedownAt`；原因为空 → `40017`（HTTP 层空值先被 `@NotBlank` 拦为 `400`）。
- `restoreCopyright()`：仅 `TAKEDOWN` 可恢复，恢复后保持 `OFFLINE`，需运营显式重新上架。
- `playable()`：`PUBLISHED` + 版权可播 + 授权未过期；`commentable()`：已发布 + 公开 + 可播放；`visibleTo(userId, operator)`：未发布 / 版权下架 / 授权过期不可见，私密内容仅本人与运营可见。
- 越权口径：`assertOwnedBy` → `40301`；`assertType` → `40401`；跨租户一律 `40401`（不泄露存在性）。

### 2.2 上传校验（`VideoUploadPolicy`）

| 校验 | 规则 | 错误码 |
|---|---|---|
| 文件可用 | 必须存在且未删除、状态正常、字节数 > 0 | `40006` |
| 视频 MIME | 精确白名单 `video/mp4`、`video/webm`（统一小写，不做前缀匹配） | `40003` |
| 图片 MIME | `image/jpeg`、`image/png`、`image/webp` | `40004` |
| 大小 | 短视频 300MB / 视频 2GB / 电影 4GB | `40005` |
| magic bytes | WebM 前 4 字节 `1A 45 DF A3`；MP4 偏移 4–7 为 `ftyp`；未知头部回落 MIME 判断 | `40003`（与 MIME 不一致时） |
| 时长 | 短视频 300s / 视频 7200s / 电影 14400s | `40002` |

### 2.3 播放票据与流式

- 票据：Redis key 含 `tenantId|userId|contentId`，TTL 300s，响应同时给 `expiresIn=300` / `refreshIn=240`；`streamUrl = /video/stream/{contentId}?ticket=...`。
- `openStream` 顺序：票据有效（缺失 / 过期 / 换用户 / 换内容 → `40302`）→ 可播缓存（`false` → `40303`，不访问仓储）→ 内容 `visibleTo` / `playable()`（`40401`）。
- 流式响应：200 全量 / 206 分段 / 416 越界（`Content-Range: bytes */total`、长度 0）；统一 `Accept-Ranges: bytes`、`Cache-Control: private, no-store`、`X-Content-Type-Options: nosniff`、透传 `ETag`。
- 批量票据：逐条跳过不可播内容，返回 `PlayTicketBatchView{tickets, rejectedContentIds}`，空 ID 列表返回空批量；播放次数仅在 200 / 206 时 `increment`，416 不计。

### 2.4 互动、进度与评论

- 点赞 / 收藏：唯一索引保证幂等，仓储 `add` 返回 `false`（已存在）时不重复累加计数。
- 观看进度：`progressMs` 不得超内容时长（`40016`）；未传来源默认 `"MY"`；上报后写入 `vd_watch_history`，支持 `pageNum/pageSize` 与 `current/size` 两种参数命名。
- 评论：`normalize` 去首尾空白、空或 >500 → `40014`；回复父评论不存在 → `40015`；删除 / 点赞幂等。

### 2.5 发现与运营

- 首页聚合 `HomeView{shorts, videos, movies, categories, tags}`，租户级 Redis 缓存 60s + 0–10s 抖动。
- 发布 / 下架 / 版权下架后 `homeCacheRepository.evict(tenantId, "HOME")` + 可播缓存失效。
- 运营接口 `@RequirePermission` + `@AuditLog`（`targetType = "vd_content"`，`targetId = "#id"`）。
- 公开 VO（`PublicContentView` / `ContentDetailView` / `PlayTicketView` / `CommentView` / `HomeView`）**不含任何 `fileId`**；封面走 `/video/content/{id}/cover`。
