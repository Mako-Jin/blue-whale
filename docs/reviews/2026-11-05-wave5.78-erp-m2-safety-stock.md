## 2. 口径与边界

- **缺料预警**：`缺口 = 安全库存量 − 在库余额`，仅返回缺口 > 0；余额缺失按 0；结果按缺口降序。
- **呆滞分析**：余额 > 0；`库龄 = 今天 − 最近 OUT 流水日期`；从未出库恒计入且库龄为空；阈值默认 90 天，`< 1` 抛 40024；排序为库龄降序（从未出库置顶）、金额降序。
- **批次追溯**：明确推迟。需 `ALTER TABLE` 既有 `erp_scm_stock_movement` / `erp_scm_stock_balance`，与「迁移仅允许 `CREATE TABLE IF NOT EXISTS`」门禁冲突。
- **补货建议 / 跌价准备**：不在本期；随 MRP 与财务成本规则（D5/D6）后续处理。
