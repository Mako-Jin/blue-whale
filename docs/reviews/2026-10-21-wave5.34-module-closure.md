## 四、风险与遗留

| 项 | 说明 | 处理 |
|---|---|---|
| 定时任务日志 Tab 未按权限码隐藏 | `sys:job:log:list` 与 `sys:job:list` 分离，非管理员角色点日志 Tab 会收到一次错误提示 | 低风险，留待角色化时统一按 Tab 控权 |
| 前端 ID 类型声明为 `number` | 后端 Long 走 `ToStringSerializer` 实际返回字符串；当前仅做模板拼接与透传，运行期无精度损失 | 与既有 admin 约定一致，不改 |
| 能力扩展 backlog | 工作流条件/并行/会签/转办、GW-01/02/03、AUTH-17/10 | 统一登记在各自 backlog 台账，不在本轮实现 |
