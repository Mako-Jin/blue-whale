## 三、关键设计取舍

1. **不新增游标表**：以台账 `MAX(source_update_time)` 作游标，所有变更（含删除/停用置 `SKIPPED`）均回写该字段，满足重启续传且少一张表。
2. **变更流纳入逻辑删除**：`/file/internal/changes` 改为自定义 SQL 显式返回 `deleted`，解决 MyBatis-Plus 逻辑删除过滤导致「删除后索引残留」的问题；对既有档案调用方无影响（档案未使用该接口）。
3. **解析线程池隔离**：Tika 解析在独立双线程池执行并设 30s 超时，避免恶意/超大文档阻塞调度线程。
4. **失败分级**：不可重试（不支持/损坏/超限）直接 `SKIPPED`；可重试（I/O/超时）记录 `FAILED` 并按指数退避，达上限后停止自动重试，保留人工重建入口。
