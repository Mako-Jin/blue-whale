## 2. 完成项

### 2.1 领域层

- `SongComment`（评论聚合根）：`TOP_LEVEL_PARENT_ID = 0`、`CONTENT_MAX_LENGTH = 500`。
  - `create(songId, userId, parent, content, preAudit)`：正文 trim 后非空且 ≤ 500（否则 `COMMENT_CONTENT_INVALID` 40014）；父评论须同歌曲且 `VISIBLE`（否则 `COMMENT_PARENT_INVALID` 40015）；先发后审（默认）新评论即 `VISIBLE`，先审后发为 `PENDING`。
  - `approve()`：非 `VISIBLE` → `VISIBLE` 返回 true（调用方据此计数 +1），已 `VISIBLE` 幂等 false。
  - `hide()`：`VISIBLE` → `HIDDEN` 返回 true（计数 -1）；`PENDING` → `HIDDEN` 不计数；重复隐藏幂等 false。
- 端口：`CommentRepository`（顶级分页 / 回复批量查询 / 审核分页）、`CommentNotificationPort`（`sendSafely` + `BIZ_TYPE_REPLY` / `BIZ_TYPE_MODERATION` 常量，通知能力以端口-适配器解耦）。
- `MusicErrorCode` 新增：`COMMENT_CONTENT_INVALID`(40014)、`COMMENT_PARENT_INVALID`(40015)、`COMMENT_NOT_FOUND`(40406)。

### 2.3 应用层与接口层

| 能力 | 说明 |

| `CommentAppServiceImpl#submit` | 校验歌曲对当前用户可见且可播（`visibleTo + playable`，否则 40403）→ 领域创建 → 可见时计数 +1 → 回复他人评论时**事务提交后**（afterCommit，无事务环境直接执行）通知父评论作者；回复自己不通知，通知文案不含评论正文 |
