## 2. 口径与边界

- 已占用 = 未结应收 + 在途预占（在途预占口径同第六期：`APPROVED` / `PARTIALLY_SHIPPED` 未发货金额）。
- 可用额度 = 额度 − 已占用；超额时为负数，同时 `exceeded = true`。
- 额度 0 视为不限：`unlimited = true`、`available = null`、`exceeded = false`。
- 查询只读，不参与审核/发货校验；校验仍由第六期两处方法执行。
- 权限仅授予四个 ERP 角色，均只读；前端按权限码显隐。
