## 2. 关键实现口径

### 2.1 短视频作品管理

- 上传 / 编辑入口：`POST /video/user/shorts`、`PUT /video/user/shorts/{id}`；创建 / 更新均要求 `videoFileId`（`@NotNull`，缺失先由 Bean Validation 拦为 `code=400`）。
- 作品列表 `GET /video/my/shorts` 返回 `PageResult<OwnerContentView>`：在公开视图基础上追加 `publishState / copyrightState / takedownReason / createTime`，**仍不含任何 `fileId`**。
- 编辑回填 `GET /video/user/shorts/{id}` 返回 `ContentView`（含 `videoFileId / coverFileId / width / height / sizeBytes`），仅内容本人可读（`requireOwned` → `40301`），跨租户 `40401`。
- 私密内容：`Content.visibleTo` 对 `PRIVATE` 仅本人与运营可见可播；`commentable()` 要求已发布 + 公开，私密内容不开放评论。
- 删除为逻辑删除：`ContentRepositoryImpl.delete` 调 `deleteById`，由 `BaseEntity` 的 `@TableLogic deleted` 落 `deleted=1`（不物理删行），并清理内容标签关联；删除后本人列表与公开入口均不可见。

### 2.2 feed 键集游标

- 排序 `LATEST`（`published_at` 降序）与 `HOT`（`hot_score` 降序），均以 `(锚点, id)` 二元组续读，避免翻页期间发布 / 下架导致的重复与漏项。
- 游标格式 `anchor|id`：`LATEST` 锚点为发布毫秒时间戳，`HOT` 锚点为 `hot_score` 十进制字符串；`FeedCursor.parse` 失败、锚点类型不匹配（如 `HOT` 传整数毫秒）一律 `400`（`feed 游标非法，请重新加载`）。
- 多取 1 条判断 `hasMore`，返回体 `FeedView{records,nextCursor,hasMore}`；每批默认 10、上限 50（`LIMIT` 通过 `wrapper.last(...)` 拼接）。
- 首屏缓存 30s，分区 `SHORT_VIDEO:{sort}:{categoryId}:{batchSize}`；发布 / 下架 / 版权下架按租户整体失效（`evictAll`），避免「缓存跨页形状不一致」。

### 2.3 播放与前端滑播

- 批量票据 `POST /video/play/ticket/batch` 返回 `{tickets, rejectedContentIds}`；滑播每批拉取后预取前 20 条票据。
- 前端预取可用性判定 `Date.now() - fetchedAt < (refreshIn - 15) * 1000`，余量不足即时换新；激活后按 `refreshIn - 5` 秒递归 `setTimeout` 刷新票据，避免长播失效。
- 滑播容器 `height: calc(100vh - 104px)` + `scroll-snap-type: y mandatory`，`IntersectionObserver(threshold 0.6)` 判定当前 slide；距末尾 2 条触发续读。
- 进度：`onLoadedMetadata` 恢复服务端 `progressMs`；播放中 15s 节流上报，暂停 / 结束立即上报（超时长由服务端判 `40016`）。
- 互动：点赞 / 收藏按本地 `interactions` 即时切换，成功后以服务端返回计数回写；评论前先取详情 `commentable`，私密 / 未发布内容不展示评论入口。

### 2.4 上传中心

- 上传前置：`GET /video/declaration/current` 未签署则弹窗（正文 + 内容来源 + 勾选），`POST /video/declaration/accept` 成功后继续。
- 视频走 `whale-file` 分片：`chunk/init`（`{fileName,contentType,size}` → `{uploadId,chunkSize,uploadedIndexes}`）→ `chunk/part`（multipart `file/uploadId/index`）→ `chunk/complete`；按服务端 `chunkSize` 切片并跳过已上传索引，前端 `Progress` 实时展示。
- 封面走普通上传 `POST /file/upload`；时长 / 宽高由前端 `<video preload="metadata">` 本地解析，避免额外探测接口。
- 分类按 `contentTypeScope` 过滤，标签按 `tagType` 过滤；可见性 `PUBLIC / PRIVATE`；提交 `publishNow=true` 直接上架，`false` 保存草稿。

### 2.5 我的作品与运营

- 我的作品分 Tabs（短视频 / 视频），`ProTable` 以 `key={contentType}` 重挂载并按 `keyword / visibility / publishState` 筛选。
- 行操作：详情（仅短视频）→ `/shorts/{id}`；编辑（先拉 `ownerView` 回填，保存时携带原 `videoFileId / coverFileId / durationMs / width / height / sizeBytes` 与 `publishNow=false`）；发布 / 下架；删除（`Popconfirm`）。
- 运营侧：分页、发布、下架、版权下架均 `@RequirePermission` + `@AuditLog`，版权下架原因展示在「版权」列 Tooltip。

### 2.6 网关与安全

- `/video/**` 直连不剥前缀；`/video/internal/**` 由 `internal-deny` 统一 403。
- 限流：`/video/stream/**` 独立限流且不进入熔断名单；票据 60/60s、评论 20/60s、点赞 / 收藏 30/60s、上传 `/video/upload/**`。
- 公开 VO（feed / 详情 / 票据）不含 `fileId`；流式响应沿用 M1 的 `private, no-store` + `nosniff` + `Accept-Ranges`。
