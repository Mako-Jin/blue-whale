### 已修正问题项

1. **MyBatis-Plus lambda 缓存缺失**：纯单测中 `LambdaUpdateWrapper` 触发 `MybatisPlus can not find lambda cache` → 测试类 `@BeforeAll` 用 `TableInfoHelper.initTableInfo` 预热实体元数据。
2. **幂等用例参数缺失**：未设置 `clientRequestId` 导致走默认状态分支报「项目未配置默认状态」→ 补齐请求参数后验证「不重复落库」。
3. **Mockito 泛型推断**：`selectBatchIds(anyCollection())` 推断不稳 → 显式 `ArgumentMatchers.<Serializable>anyCollection()`。
4. **排序空间不足**：直接失败会导致拖拽卡死 → 项目内局部重排（先 TMP 值再 1000 步长双 pass，规避 `uk_tenant_project_rank` 冲突）。
5. **状态直改入口**：更新接口直接改 `statusId` 会绕过状态机 → 显式拒绝，统一走 `/work-item/{id}/transition`。

3. 评论删除会级联删除回复，暂不提供「仅删除自己回复」的细粒度入口。
4. 工作项删除为逻辑删除并级联解除评论 / 附件 / 关联引用，动态表保留全量轨迹。
