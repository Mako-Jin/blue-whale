## 2. 完成项

### 2.1 服务骨架（M0-2）

- 新增 `whale-backend/whale-services/whale-music`：单模块 + 四层分包，端口 `8096`、服务名 `whale-music`、库 `bluewhale_music`、包 `com.bluewhale.music`。
- `WhaleMusicApplication`：`@SpringBootApplication` + `@EnableDiscoveryClient` + `@EnableScheduling` + `@EnableConfigurationProperties(MusicProperties.class)`。
- `application.yml`：数据源 + Hikari 基线（`${DB_POOL_MAX_SIZE:5}` / `${DB_POOL_MIN_IDLE:2}`）、Redis、Nacos discovery/config、`whale.permission.header.enabled=true`。
- `MusicProperties`（`whale.music.*`）：协议版本 / 协议标题 / 上传上限 100MB / 音频格式 `audio/mpeg,audio/aac,audio/flac` / 封面格式 / 播放票据 TTL 120s / 流式分块 1MB / 评论先发后审开关 / 歌单上限 500 / 播放历史保留 90 天 / file 服务名。
- `GET /music/meta`（`sys:music:browse`）：返回服务名、租户、用户、协议版本与标题、上传开关与上限、可接受音频格式、票据 TTL、评论审核开关，供前端在登录后一次性取得上传前置条件。

### 2.2 数据模型（M0-3）

`db/init.sql` 含建库语句与 11 张业务表：

| 表 | 用途 |
|---|---|
| `mu_artist` | 歌手 |
| `mu_album` | 专辑 |
| `mu_song` | 歌曲（含 `uploader_id` / `visibility` / `copyright_status` / `takedown_reason`） |
| `mu_copyright_agreement` | 版权无争议协议签署记录（唯一键 `(tenant_id,user_id,agreement_version)`） |
| `mu_tag` / `mu_song_tag` | 标签与歌曲标签 |
| `mu_playlist` / `mu_playlist_song` | 歌单与歌单曲目 |
| `mu_song_like` | 收藏 |
| `mu_play_history` | 播放历史 |
| `mu_song_comment` | 评论 |

另含 `audit_log` / `api_log` 两张横切表。所有业务表带 `tenant_id` 与逻辑删除列。

### 2.3 领域骨架（M0-4）

- 枚举：`SongVisibility`（PUBLIC/PRIVATE）、`PublishState`（DRAFT/PUBLISHED/OFFLINE）、`CopyrightState`（DECLARED/VALID/TAKEDOWN，`canPlay()` 仅非下架为真）、`PlaylistVisibility`、`PlaylistType`、`CommentStatus`。
- 值对象：`SongTitle`（去空白、非空、≤120 字符，非法入参抛 `IllegalArgumentException`）。
- ArchUnit 5 条规则：domain 不依赖外层、domain 不依赖框架、application 不依赖 interfaces/infrastructure、interfaces 不依赖 domain/infrastructure、infrastructure 不依赖 interfaces。

### 2.4 网关与权限（M0-5）

- 网关新增 `whale-music`：`Path=/music/**` → `lb://whale-music`，**不配 `StripPrefix`**（REQ-ARCH-003）。
- 限流：`/music/stream/**` 120 次/60s（`WHALE_GATEWAY_RATE_LIMIT_MUSIC_STREAM`）；`/music/song/*/comment` 20 次/60s。
- 熔断 `apply-to-routes` 与 `internal-deny`（`/music/internal/**` 403）纳入 `whale-music`。
- 迁移脚本 `migration-5.75-music.sql`（`bluewhale_auth`，全量幂等）：
  - 权限点 **280–302**（23 项）：artist 280–283、album 284–288、song 289–293、tag 294、官方歌单 295、评论审核 296、统计 297、浏览 298、自建歌单 299、评论 300、收藏 301、上传与我的作品 302。
  - 角色：平台 25103 `music_admin`、25104 `music_member`；业务租户按 MD5 前缀复制同名角色。
  - 授权：`tenant_admin` / `music_admin` 获 280–302；`music_member` 获 298–302。
  - **所有人可上传**：`music_member` 幂等授予全部启用用户。
  - 菜单 **39–44**：音乐中心 `/music` + 曲库 / 歌手与专辑 / 歌单与标签 / 评论审核 / 播放统计。

> **M1 修正（2026-10-31）**：280 已被 `sys:file:manage`（`init.sql` / `5.76`）占用，上述权限号整体顺延为 **281–303**（对应关系 +1），授权区间为 281–303 / 299–303；并新增 5.1 段为 `music_member` 补齐 `sys:file:upload`(32) / `artist:list`(281) / `album:list`(285)。详见 [M1 检查报告](2026-10-31-wave5.75-music-m1.md) 问题 #6 / #7。
