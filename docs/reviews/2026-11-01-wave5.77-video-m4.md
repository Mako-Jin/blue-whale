## 2. 关键实现口径

### 2.1 电影聚合与授权

- 电影复用 `vd_content` 作为统一内容注册（`contentType=MOVIE`、`visibility=PUBLIC`、`uploaderId=0`、创建即 `DRAFT`），`vd_movie` 以 `contentId` 为 1:1 扩展，保存原始片名 / 导演 / 主演 / 地区 / 语言 / 上映日期 / 评分 / 授权信息 / 海报与背景图文件 ID。
- 授权来源 `MovieLicenseSource`：`OWNED / LICENSED / PUBLIC_DOMAIN`；同时映射内容版权来源 `CopyrightSource`（`ORIGINAL / AUTHORIZED / ROYALTY_FREE`），并把授权到期写入 `vd_content.copyright_expire_at`，播放票据与流式读取据此阻断。
- 入库校验顺序：授权字段（来源 / 到期 / 编号）→ 视频资产存在 → 12 字节头部 → MIME / magic bytes / 大小 → 分类 → 时长（`>0` 且 ≤ 电影时长上限）→ 海报 / 背景图（图片 MIME 白名单）。
- 编辑时视频文件、时长、宽高为**可选**（`>0` 才覆盖），但授权来源与到期时间**每次必须重新提交**（`applyLicense` 不接受空值），因此前端编辑弹窗强制重新选择到期时间。
- 发布要求授权仍有效（`licenseExpireAt > now`）；授权到期任务每日 03:10 将仍为 `PUBLISHED` 且授权已到期的电影置为 `OFFLINE`，失败仅告警不中断批次。

### 2.2 片单

- `vd_collection` + `vd_collection_item`（`uk(collection_id, content_id)` + `idx(collection_id, sort_no)`）；片单创建即草稿，上架 / 下架不影响片单内电影状态。
- 加片仅允许已入库的电影（非电影或不存在 → `40401`）；同一片单重复加片幂等返回详情；单片单最多 200 部；加 / 移除后刷新 `item_count`。
- 用户侧 `GET /video/collections/page` 只返回已上架片单，`GET /video/collections/{id}` 对草稿 / 不存在统一 `40405`，详情内电影按内容自身可见性过滤。
- 封面代理 `/video/collections/{id}/cover`：无封面或文件不可用 → `404`。

### 2.3 榜单、搜索与统计

- 榜单复用 `ContentQuery.sortBy=HOT / LATEST`：`type` 空白表示跨类型，非法值 → `PARAM_ERROR(400)`；条数默认 10、上限 50（复用 feed 上限常量）。
- 搜索沿用 M1：关键词空白返回稳定空分页；只返回当前租户已发布、公开、版权有效且对当前用户可见的内容。
- 统计概览 10 项：内容总数 / 已发布 / 短视频 / 视频 / 电影 / 播放合计 / 待审核评论 / 临期授权 / 片单 / 创作者；`expiringDays` 默认 7 天、`Math.max(days, 1)`。
- 创作者停用后 `active=false`，内容发布链路拒绝；头像上传校验图片 MIME，`avatarFileId=0` 清除；运营视图只返回代理地址。

### 2.4 前端（`frontend/platform-apps/whale-video`）

- `api/video.ts`：`MovieView / MovieDetailView / MovieCollectionView / MovieCollectionDetailView / RankingView` 与 `fetchMoviePage / fetchMovieDetail / fetchCollectionPage / fetchCollectionDetail / fetchRankings / buildCollectionCoverUrl`。
- `MoviesPage`：热门 / 新片榜单 + 分类筛选 + 关键词搜索 + 已上架片单 + 电影分页（`12` 条 / 页，空态与 403 / 404 处理）。
- `MovieDetailPage`：播放器 + 导演 / 主演 / 地区 / 语言 / 上映日期 / 评分 + 收录片单 + 点赞 / 收藏 / 评论入口。
- `CollectionDetailPage`：片单信息 + 片单内电影网格（封面、时长、评分、可播标记）。
- `VideoLayout` 导航与 `App` 路由补充 `/movies`、`/movies/:id`、`/collections/:id`，`/movies` 与 `/collections` 高亮归入「电影」。
- 首页文案由「M3 / M4 开放」占位更新为「短视频 / 视频 / 电影已开放」，避免上线后提示过期。

### 2.5 运营前端（`frontend/admin`）

- `api/video.ts` 追加 M4 契约：电影运营视图 / 查询 / 保存、片单视图 / 详情 / 查询 / 保存、统计概览、评论审核、创作者分页与编辑，共 24 个函数。
- `MovieList`：海报缩略图、授权来源 / 编号 / 到期（过期标红）、发布（授权有效期由后端复核）、下架、版权下架（原因必填抽屉）、删除；入库 / 编辑弹窗含视频上传、海报 / 背景图上传与移除（`0` 清除）。
- `CatalogPage` 改为 Tabs 外壳：`SeriesPanel`（原系列管理逻辑迁移）、`CollectionPanel`（片单 + 影片抽屉 + 选片弹窗，仅列已发布电影）、`CreatorPanel`（资料 / 头像 / 启停）。
- `CommentAudit`：状态过滤 + 通过 / 隐藏（Popconfirm + 行级 loading）。
- `StatPage`：内容与播放、内容类型分布、运营待办（待审核评论 / 临期授权），窗口可调 1–90 天并可刷新。

## 4. 设计决策与本次修正

| 项 | 决策 / 处理 |
|---|---|
| 电影复用 `vd_content` | 不新建独立电影内容表，复用统一内容注册与播放 / 互动 / 可见性链路；`vd_movie` 仅做 1:1 元数据扩展，避免三套内容模型分叉 |
| 授权到期写入内容 | `vd_movie.license_expire_at` 同步 `vd_content.copyright_expire_at`，票据与流式读取双重阻断；定时任务只负责状态兜底 |
| 编辑强制重提授权 | 后端 `applyLicense` 不接受空来源 / 空到期，避免「编辑时把授权清空」绕过合规；前端编辑弹窗以「当前值 + 重新选择」提示 |
| 片单唯一性 | DB 唯一键 + 应用层 `existsItem` 双保险，重复加片直接返回详情（幂等）；逻辑删除下仍依赖应用层判断，避免历史行占用唯一索引 |
| 片单条目过滤 | 用户侧详情按电影内容自身可见性过滤，片单下架不影响电影，电影下架也不删除条目（重新上架后自然恢复展示） |
| 榜单复用内容查询 | 不引入独立榜单表 / ESPN，按 `sortBy=HOT / LATEST` 取已发布公开内容并在应用层按用户可见性过滤；上限复用 feed 50 |
| M4-8 提醒口径 | 计划标注为「可选消息」，本次以统计页临期数量 + 每日下线任务兜底；不新增消息依赖，避免把通知链路风险带入 M4 |
| 前端 `CreatorPanel` 类型错误 | `render: (value?: string, row)` 触发 `TS1016`（必选参数跟在可选参数后）→ 改为 `value: string \| undefined` |
| 前端 `MoviesPage` 未使用变量 | `const { message } = App.useApp()` 未读取 → 删除并移除 `App` 导入，满足 `noUnusedLocals` 与 lint |
| 创作者「创建时间」列 | 后端 `CreatorAdminView` 无 `createTime` 字段，列恒为 `-` → 移除该列，避免误导 |
| 首页占位文案 | 「视频将在 M3 开放 / 电影将在 M4 开放」已过期 → 更新为已开放文案与空态提示 |
| 冒烟脚本迁移文件名 | 头注释误写 `V2__movie.sql`，实际为 `V2__series.sql` → 修正为 `V1 / V2__series / V3__movie_collection` |
| 图片代理鉴权 | 海报 / 背景图 / 片单封面 / 头像与既有封面代理一致，浏览器 `<img>` 无法携带鉴权头；部署层签名 URL 或票据方案仍待确认 |
