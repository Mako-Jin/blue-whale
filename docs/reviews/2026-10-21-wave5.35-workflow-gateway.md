## 四、缺陷与修复记录

| 缺陷 | 根因 | 修复 |
|---|---|---|
| resilience4j 启动报 `waitDurationInOpenState must be at least 1[ms]` | 配置允许 0ms | 代码 `Math.max(1, …)`；单测改 1ms 并等待 5ms 半开探测 |
| 冒烟 `UNKNOWN_DEFINITION_TYPE` | 手工脚本用 `type='normalized'` | 规范化模型固定 `type='stateMachine'` |
| PowerShell 单元素 `.Count` 为 null | `Invoke-RestMethod` 返回 PSCustomObject | 统一 `@($x).Count` |
| 实例终态断言错误 | 通过状态是 `1` 不是 `2` | 断言改 1 |
| resolve 后未回到 admin | 语义为「回到委派人」（transfer 后为 alice） | 断言改 alice（DB：bob 任务 status=3，新任务 assignee=alice） |
| 表单 PUT 404 | 原记录 `deleted=1` | 改用未删除记录 |
| Nacos 动态路由不加载 | 网关命名空间 `public`，配置发布在默认租户 `""` | 发布/读取统一带 `tenant=public` |
| `POST /actuator/routeGovernance` 415 | PowerShell 无 body/Content-Type | 显式 `-ContentType 'application/json' -Body '{}'` |
| 同一配置重复刷新覆盖 previous | 一次发布触发多次刷新事件 | `sameAsCurrent`/`signature` 去重 + 单测 |
| **回滚后被刷新覆盖回新版** | rollback 发布 `RefreshRoutesEvent` 后重新读到 Nacos 中仍为新版的配置 | `abandonedSignatures` 回滚固定标记：内容仍等于被放弃版本即保持回滚快照；真实新配置到达后自动失效；新增 2 个单测 |

## 五、遗留与风险

| # | 项 | 说明 |
|---|---|---|
| 1 | 转办弹窗确认未自动化验证 | 后端端点已冒烟闭环；前端 Modal 在自动化环境点击被判定视口外，建议人工点一次「转办 → alice」 |
| 2 | 设计器拖拽手势 | @dnd-kit `PointerSensor` 不接受合成 PointerEvent（Wave 5.29/5.30/5.32 同一限制），需人工复核 |
| 3 | 网关快照为进程内 | 多实例各自维护 current/previous，回滚只在当前实例生效（与本地限流/熔断语义一致） |
| 4 | 动态路由 rollback 不回写 Nacos | 回滚是网关实例内的应急动作，Nacos 中仍是新版；如需全局回滚需重新发布上一版配置 |
| 5 | AUTH-10 审计 MQ 汇聚 | 本机无 RabbitMQ，维持 backlog；阶段一跨库可见性约束仍在 |
