### 1.4 对象键 `tenants/` 前缀迁移

执行 SQL（幂等）：

```sql
UPDATE bluewhale_file.file_info
SET object_key = CONCAT('tenants/', tenant_id, '/', object_key)
WHERE object_key NOT LIKE 'tenants/%';
```

结果：`file_info` 共 7 行，迁移前 0 行带前缀，迁移后 **7/7 全部带 `tenants/1/` 前缀**。
边界：本地存储根 `D:\data\whale-file` 下 `whale-archive` 桶为空，**无物理对象需要搬移**；若其他环境使用 MinIO/远端对象存储，需要同步执行对象搬移后再更新 `object_key`（脚本/SQL 未固化到仓库，执行语句见上）。
