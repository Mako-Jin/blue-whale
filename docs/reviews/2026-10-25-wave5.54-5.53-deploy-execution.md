## 五、追加执行（2026-10-25 晚）：租户开通缺陷修复 + §14.4 / S4 冒烟

### 5.1 缺陷：开通租户返回 500（空指针）

- **现象**：`POST /tenant` 创建 `acme` 返回 `{"code":500,"message":"系统异常"}`，数据库无残留（事务整体回滚正确）。
- **堆栈**：`NullPointerException: Cannot invoke "java.lang.Long.longValue()" because the return value of "java.util.Map.get(Object)" is null`，首帧
  [TenantProvisioningAppService.java:143](file:///f:/blue-whale/backend/whale-services/whale-auth/src/main/java/com/bluewhale/auth/application/tenant/TenantProvisioningAppService.java#L142-L146)。
- **根因**：菜单模板复制按「轮次重试」处理父子乱序（子菜单先于父菜单返回时应 `continue` 等下一轮），但代码 `source.getParentId() == 0L ? 0L : idMapping.get(...)` 的三元两端分别为原始 `long` 与 `Long`，编译期被统一为 `long`，`idMapping.get()` 为 `null` 时自动拆箱抛 NPE。真实库中 `sys_menu` 查询顺序不保证父在子前，因此必现。
- **修复**：三元两端统一为 `Long`（`Long.valueOf(Menu.ROOT_PARENT_ID)`），保留 `null` 判断走「下一轮重试」。
- **回归**：新增 `TenantProvisioningAppServiceTest#shouldCopyMenusWhenChildListedBeforeParent`（故意子菜单前置），`TenantProvisioningAppServiceTest` 4 用例全绿。
