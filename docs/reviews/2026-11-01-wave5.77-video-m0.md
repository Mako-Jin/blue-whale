### 2.2 G1 大文件上传策略（方案 B：按权限码）

- `FileProperties.uploadPolicy`：`enabled` 开关 + `rules` 列表，默认规则：
  - `sys:video:upload` → 单文件 **2GB** / 配额 **8GB**；
  - `sys:video:movie:manage` → 单文件 **4GB** / 配额 **不限**（`quotaBytes<=0`）；
  - `sys:music:upload` → 单文件 100MB / 沿用全局配额；
  - `super_admin` → 命中全部规则中的最大上限。
- `FileUploadPolicy.resolve(permissionCodes)`：只读网关可信注入的 `X-Permission-Codes`（客户端伪造同名头在网关侧被剥离）；同一请求命中多条时取**单文件上限最大**的一条；未命中回落 `whale.file.max-size-bytes`（50MB）/ `whale.file.quota-bytes`（1GB）。
- 落地位置：`upload` / `rapidUpload` / `quota` / `initChunkUpload` / `completeChunkUpload` 全部按生效上限校验；`init` 记录生效上限与配额到会话元数据，`complete` 取「init 登记」与「当前请求」两者**更严格者**，任一阶段权限被回收都会失败。
- 既有 Range 能力（音乐 G1 已交付）回归：`LocalChunkUploadStoreTest` 覆盖 2GB 元数据持久化。

### 2.3 网关与权限

- 路由：`/video/**` → `lb://whale-video`；`/video/internal/**` 由 `internal-deny` 统一 403。
- 限流：`/video/stream/**` 120/60s、`/video/play/ticket` 60/60s、`/video/content/*/comment` 20/60s、`/video/content/*/like|favorite` 30/60s、`/video/upload/**` 20/60s，均可用环境变量覆盖。
- **不加入** `circuit-breaker.apply-to-routes`（长视频一次播放跨多个 Range 请求，避免 3s 超时误熔断）。
- 权限 305–322（18 项）：305–313 运营（内容增删改、发布、下架、版权下架、评论审核、统计），314 浏览、315 上传与我的作品、316 点赞、317 收藏、318 评论、319 分类标签、320 系列、321 电影与授权、322 创作者。
