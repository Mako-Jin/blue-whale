## 二、完成项

### 2.1 数据库

- `V8__change_order.sql`：
  - `pdm_chg_order`：编号、来源 ECR、标题、影响评估、影响对象快照、执行计划、状态、发起/审批/执行/完成/关闭信息；`uk_chg_order_no(tenant_id, eco_no)`，索引 `idx_chg_order_status`/`idx_chg_order_ecr`。
  - `pdm_chg_task`：所属 ECO、任务名/类型、目标对象、执行说明、负责人、状态、结果版本号、排序；索引 `idx_chg_task_eco`/`idx_chg_task_sort`；不建排序唯一键。
  - 仅 `CREATE TABLE IF NOT EXISTS`，无 `DROP/TRUNCATE/DELETE`、无物理外键。
- `migration-5.80-pdm-eco.sql`（`bluewhale_auth`）：权限 956–962、菜单 191；`tenant_admin/pdm_manager/pdm_change_manager` 获得 956–962，`pdm_member` 仅 956；全部 `NOT EXISTS` 幂等，无删除语句，不新增角色。

### 2.2 后端

- 实体/Mapper：`PdmChgOrder`、`PdmChgTask`（继承 `BaseEntity`，`tenant_id` 由租户拦截器写入）；状态常量 `PdmChgOrderStatus`/`PdmChgTaskStatus`。
- 服务 `PdmChgOrderServiceImpl`：
  - `create` 仅 `APPROVED` ECR 可建，原样快照 `impact_json`，编号 `EO-yyyyMMddHHmmss-四位随机`；
  - `update/delete` 仅草稿（删除级联任务）；`assess` 仅草稿且影响评估必填；
  - 任务增删改仅草稿/评估中，目标类型复用 `PdmChgObjectType` 校验；
  - `submit` 仅评估中，要求影响评估非空且至少 1 个任务；
  - `approve/reject` 仅审批中，驳回意见必填；
  - `execute` 仅已通过，否则抛含 `CHANGE_NOT_APPROVED` 的错误；
  - `completeTask` 仅执行中、任务待完成，结果版本号经 `PdmVersionNo.parse(...).value()` 归一化；
  - `complete` 要求全部任务完成；`cancel` 允许草稿/评估中/审批中/已通过；`close` 允许已完成/已驳回/已取消；
  - `page` 单页上限 200，详情内嵌按 `sort_no,id` 排序的任务。
- 控制器：17 端点，权限码与审计注解齐全；审批请求加 `@Valid`，审批意见可空、驳回服务侧强校验。
- 租户隔离：按 ID 查询跨租户不可见；任务完成额外校验 `ecoId`，防止跨变更单操作。

- `App.tsx`：`/change/order` 菜单（`sys:pdm:change:order:list`）与路由。
