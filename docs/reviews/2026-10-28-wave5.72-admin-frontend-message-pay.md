## 3. 未验证 / 风险

1. 浏览器自动化的表单提交与截图受步数预算限制，模板「新增」最终以接口侧（与前端相同 payload）验证 CRUD；页面渲染与菜单已由浏览器确认。
2. 支付仍为 mock 渠道：前端「支付/退款」展示的是 mock 流转结果，真实渠道接通后无需改前端（后端适配器边界已隔离）。
3. 菜单图标字段（`notification`/`money-collect`）暂存 DB，admin 侧边栏当前未渲染图标，仅作数据预留。
4. portal 未读角标轮询为 30s 定时器，未做 WebSocket 推送（消息服务边界既定：送达即止，实时性按需后续增强）。
