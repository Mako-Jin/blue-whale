## 三、问题与修正

| # | 问题 | 修正 |
|---|---|---|
| 1 | 导出 HTML 会把 `javascript:` 链接原样输出 | 新增 `safeLinkHref`；非法协议降级纯文本，并补单元测试 |
| 2 | Markdown 导入可写入 `javascript:` 链接 | 导入侧同样走 `safeLinkHref`，非法链接不生成 mark |
| 3 | 文档搜索/保存缺少业务指标，无法量化 SLO | 新增 `DocMetrics` 与 HTTP 直方图桶 |
| 4 | 页面物理清除后可能残留附件引用 | 新增孤儿清理任务 + 内网手工触发 + 指标 |
| 5 | 备份脚本未指定 MySQL 用户，默认使用系统用户被拒 | 显式 `--user=root` 与长选项 `--host/--port` |
| 6 | M5 冒烟 20 并发脚本换行导致语法错误 | 链式调用改为单行 |
| 7 | `revision + 1` 断言受 JSON 数值类型影响 | 双方显式 `[long]` 转换 |
| 8 | 前端工具栏图标按钮无可访问名称 | 补 `aria-label` |
| 9 | 小屏空间工作台横向溢出 | 新增 ≤768px 纵向堆叠与限高样式 |
