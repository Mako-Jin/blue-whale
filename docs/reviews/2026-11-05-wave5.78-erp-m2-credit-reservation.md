## 2. 口径与边界

- **占用**：未结应收（`ArApAppService#outstandingReceivable`）+ 在途预占。
- **在途预占**：`APPROVED` / `PARTIALLY_SHIPPED` 状态订单的未发货金额。
  - `DRAFT` 不计入（未承诺）；
  - `CANCELLED` 不计入（已释放）；
  - `SHIPPED` / `CLOSED` 不计入（已全部转应收）。
- **不重复占用**：发货时预占随已发货金额同额减少、应收同额增加，故发货校验不再叠加本次发货金额。
- **额度 0** 仍视为不限，与既有规则一致（避免改变存量客户行为）。
- **D8 暂定**：本片按「审核即占用、发货即释放、取消即释放」落地；如业务改为「建单即占用」或需超限审批，需在 D8 定稿后调整。
- **并发边界**：实时汇总为事务内读快照，无行锁；高并发下仍可能多单同时通过审核。后续可由 D8 决议引入预占表 + 唯一约束/行锁。

## 4. 待做与偏差

- 客户信用占用（应收 + 在途 + 可用）尚未暴露到前端客户详情。
- 高并发超额风险未消除（无预占表/行锁），依赖 D8 定稿。
- 多币种：占用按订单币种直接相加，跨币种客户需汇率口径（D1–D7 未定）。
