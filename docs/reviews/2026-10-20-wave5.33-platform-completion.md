## 二、① whale-i18n 消息 CRUD（已完成）

### 2.1 交付物

- 新增服务模块 `backend/whale-services/whale-i18n`（base 包 `com.bluewhale.i18n`，端口 `${SERVER_PORT:8087}`，库 `bluewhale_i18n`）。
- 复用 `whale-i18n-sdk`：`SysI18nMessage` / `SysI18nMessageMapper` / `I18nCacheEvictHelper`（写后清 `whale:i18n:{locale}:{code}`）。
- 5 端点（`/i18n/message`）：`page` / 详情 / `create` / `update` / `delete`；`@RequirePermission("sys:i18n:*")` + 写操作 `@AuditLog`。
- 接线：`whale-services/pom.xml` 注册模块；`whale-gateway` 新增 `/i18n/**` 路由；`whale-auth` 权限种子 **60–63**。
- DDL：`whale-i18n/src/main/resources/db/init.sql`（`sys_i18n_message` + 2 条种子）。

### 2.2 关键设计决策

- **新建服务而非改造 SDK**：i18n-sdk 是库、无任何服务消费，且平台约定「服务自持一级前缀 + DB-per-service」，故以独立服务承载 REST 宿主。
- **不加 `@ConfigurationPropertiesScan`**：避免与 SDK 的 `@EnableConfigurationProperties` 重复注册同一 `WhaleI18nProperties`。
- **写后清缓存**：`create` 清新键；`update` 键变更时先清旧键再清新键；`delete` 清键，保证 DB > 属性文件 > 默认值的三级回退不读到脏值。
