## 二、变更点

### 轨道 A：whale-job（T5.24）

- `pom.xml` 增 `whale-spring-boot-starter` / `whale-auth-sdk`；`application.yml` 端口 `${SERVER_PORT:8082}`（修正循环占位符）+ `datasource`（`bluewhale_job`）+ `whale.permission.header.enabled: true`。
- 新增 `entity/{JobInfo,JobLog}`、`mapper/*`、`scheduler/{JobHandler,JobScheduler}`、`scheduler/handler/DemoJobHandler`、`service/*` + `impl/*`、`controller/JobController`、`dto/*`(5)、`vo/*`(2)。
- 调度引擎：`ThreadPoolTaskScheduler` + `CronTrigger`（无新增依赖）；启动装载 + 增删改后重排。
- whale-auth `db/init.sql` 追加 `sys_permission` id **26–31**（6 权限点）。

### 轨道 B：AUTH-15 DDD 第 2 步

- 新增 `domain/user/{aggregate/User, entity/UserRoleAssignment, repository/UserRepository}`（domain 无框架注解；私有构造器集中校验 + 工厂 `create`/`reconstitute` + 行为 `enable`/`disable`）。
- 新增 `infrastructure/persistence/{assembler/UserPersistenceAssembler（手写）, repository/UserRepositoryImpl}`（复用既有 `SysUser`/`SysUserRole` Mapper）。
- `security/UserDetailsServiceImpl` 改注入 `UserRepository`（REST 契约不变）。

### 轨道 D：审计残余

- 新增 `common/audit/annotation/Sensitive`（字段级脱敏兜底）；`SensitiveDataMasker` 增 `maskJson(Object,String)` 重载 + 反射收集 `@Sensitive` 字段；`AuditLogAspect#resolveResultBody` 改传返回体实例。
- `LogIngestController` 四查询方法各补 `@AuditLog(type=QUERY, recordResult=false, targetType=<通道表>)`。

### 实机发现并修复（新增项）

- **D-d**：建库 `bluewhale_audit` + 应用 `whale-audit/db/init.sql`（5 表）。此前库缺失，审计落库/查询全报 `Unknown database 'bluewhale_audit'`。
- **D-e**：网关白名单/限流过宽缺陷——`/audit/log/frontend/**` 连带放行了需鉴权的 `/audit/log/frontend/page`，网关跳过 JWT → 漏注入 `X-Permission-Codes` → 下游 403；改为仅放行/限流 `/audit/log/{frontend,behavior}/batch`。
