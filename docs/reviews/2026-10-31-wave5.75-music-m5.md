## 2. 完成项

### 2.1 领域层（M5-1 / M5-2 / M5-3）

| 组件 | 说明 |
|---|---|
| `UploadPolicy`（领域服务） | 纯规则判定，顺序固定为「可用性 → 大小 → MIME 白名单」：`asset==null / fileId==null / !usable / sizeBytes<=0` → `40019`；超 `maxBytes` → `40018`；音频不在白名单 → `40016`、封面 → `40017`。白名单与上限由应用层从配置传入，领域层不依赖配置来源 |
| `FileAsset` / `FileAssetPort` | 文件元数据值对象（`fileId`/`mimeType`/`sizeBytes`/`usable`，`hasType()` 大小写不敏感）与领域端口；Application 层通过端口读取 `whale-file` 元信息，不直接依赖 HTTP 客户端 |
| `CopyrightSource` | `ORIGINAL` / `AUTHORIZED` / `ROYALTY_FREE`；`parse()` 缺失 → `40020`、非法值 → `40021`，大小写不敏感 |
| `Song#applySource` / `Song#takedown` / `Song#visibleTo` | 下架原因必填（`40005`）并强制 `copyrightState=TAKEDOWN` + `publishState=OFFLINE`；`visibleTo` 对非运营者隐藏未发布 / 下架 / 他人自听作品 |
| `MusicErrorCode` | 新增 `40016`–`40021`；补齐 `40301`–`40304`、`40403`–`40406` 文案与 HTTP 映射 |

## 4. 冒烟记录（M5）

### 4.1 安全冒烟 `scripts/smoke/bw-music-m5-smoke.ps1`

覆盖：上传白名单（音频 / 封面 / 超限 / 不可用文件）→ 来源必填与非法取值 → 协议签署前置 → 越权矩阵（跨租户 / 自听作品 / 私有歌单 / 评论 / 附件）→ 票据绑定（缺票 / 换用户 / 换歌曲）→ 版权下架与留痕 → **M5-3 申诉闭环（提交 / 空理由 / 重复申诉 / 非本人 / 通过恢复版权 / 二次复核 / 驳回）** → 清理。
