# Wave 5.80 PDM M1B-5 ERP 物料/库存只读契约 评审

> 评审日期：2026-11-06
> 规格：[spec.md](../specs/2026-11-06-wave5.80-pdm-m1b-erp-read/spec.md)
> 关联计划：[Wave 5.80 PDM 全景计划](../plans/2026-11-04-wave5.80-pdm-panorama.md)

## 一、范围

- ERP：物料按编码只读查询、库存按物料编码聚合、两个 `/erp/internal/**` 接口。
- PDM：客户端只读方法、`/pdm/part/{id}/erp-stock` 回显与降级、零件库「ERP 库存」弹窗。
- 网关：复用既有 `/erp/internal/**` internal-deny，不改配置。

## 二、设计要点

| 项 | 决策 |
|---|---|
| 物料编码 | 优先 `pdm_product.erp_item_code`，未维护回退零件编码（与 PDM→ERP 同步一致） |
| 库存口径 | 直接聚合 `stock_balance` 现有数量，不计算预占/可用量 |
| 失败策略 | PDM 捕获 ERP 调用异常，返回 `degraded=true` + 空库存，不抛 500 |
| 鉴权 | 复用 `InternalTokenSupport` 内网令牌 + 租户头；PDM 查询接口用 `sys:pdm:part:list` |
| 表结构 | 无新增表/迁移，不触碰 `stock_balance` 语义 |

## 四、风险与遗留

- 库存为全仓数量合计，未区分可用/冻结；若后续引入预占需扩展视图字段。
- 单零件回显为两次内网调用（物料 + 库存），未做合并；调用量低，暂不优化。
- 未做真实 ERP 联调，仅单测覆盖解析与降级分支。
