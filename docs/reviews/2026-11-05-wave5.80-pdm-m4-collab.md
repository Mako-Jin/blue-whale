### 后端

| 能力 | 实现 |
|---|---|
| 交付物 | 文档版本 `RELEASED`；BOM/路线 `RELEASED` 且版本一致；重复归档 409；解除归档；分页按项目/类型/关键字 |
| 评审 | `DRAFT → CLOSED`；结论三值校验；关闭后拒绝修改/重复关闭；草稿可删；附件文档/版本存在性校验 |
| 预览 | `documentId:versionId:previewType` 幂等；PDF/图片/STL/glTF 原生成功；Office/DWG/STEP 给出 `UNSUPPORTED` 原因；重试累计次数；内容读取复用 `PdmDocDocumentService.download`，不暴露 `fileId` |
| 检索 | 文档关键字扩展到 `description` 与 `ownerName` |
| 审计 | 归档/解除/评审增改删关/预览创建重试读取均 `@AuditLog` |
| 权限 | 980–989 分权；菜单 198–200；角色 21107 |
