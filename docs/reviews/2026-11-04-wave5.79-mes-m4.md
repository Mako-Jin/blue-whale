## 2. 变更清单

### 2.1 数据库迁移

`whale-backend/whale-apps/whale-mes/src/main/resources/db/migration/V7__mes_equipment_collect.sql`

- 设备：`mes_eq_equipment`、`mes_eq_status_event`、`mes_eq_downtime`；
- 保养与维修：`mes_eq_maintenance_plan`、`mes_eq_maintenance_order`、`mes_eq_repair_order`；
- 备件：`mes_eq_spare_part`、`mes_eq_spare_part_stock`、`mes_eq_spare_part_movement`；
- OEE：`mes_eq_oee_snapshot`；
- 采集：`mes_cl_device`、`mes_cl_collection_point`、`mes_cl_metric_sample`、`mes_cl_board_config`、`mes_cl_archive_policy`；
- 关键唯一键：设备 `(tenant_id, equipment_code)`、备件 `(tenant_id, part_code)`、库存 `(tenant_id, part_id, warehouse_code)`、
  采集设备 `(tenant_id, device_code)`、采集点 `(tenant_id, point_code)`、
  样本 `(tenant_id, point_id, sampled_at, seq)`、OEE `(tenant_id, equipment_id, shift_date, shift_code)`；
- 台账、停机、保养计划/工单、维修、备件、库存、OEE、采集设备/采集点/看板/归档含 `version` 乐观锁；
  状态事件、样本、流水为只追加，无 `version`；全部表含 `tenant_id` / `deleted`。

### 2.2 后端（`com.bluewhale.mes.equipment` / `com.bluewhale.mes.collect`）

- 实体 / Mapper（15 组）：设备、状态事件、停机、保养计划、保养工单、维修工单、备件、备件库存、备件流水、
  OEE 快照、采集设备、采集点、采集样本、看板配置、归档策略。
- `MesEquipmentService`：
  - 台账：`saveEquipment`、`getEquipment`、`pageEquipments`，编码为空自动生成 `EQP-*`，唯一冲突拒绝；
  - 状态：`changeStatus` 追加事件，`sourceEventId` 幂等；`FAULT` 开停机、离开关停机；`gate` 输出可开工判定；
  - 保养：`savePlan`、`pagePlans`、`createOrder`、`startOrder`、`completeOrder`、`acceptOrder`；
    完工结果按 `项名=结论` 逐行解析，必须覆盖全部保养项且无多余/重复；
  - 维修：`createRepair`、`assign`、`start`、`verify`、`close`，状态不可跳转，关闭回填停机时长；
  - 备件：主档保存、出入库、库存与流水查询；库存先查后改，`after < 0` 拒绝；
  - OEE：`computeOee` 默认公式，`formulaConfig` 允许覆盖口径并留痕；`pageOee` 查询快照。
- `MesCollectService`：
  - 设备：`saveDevice`、`pageDevices`、`heartbeat`（停用拒绝、`ONLINE` + 心跳时间）；
  - 采集点：`savePoint`、`pagePoints`，编码生成/唯一，绑定设备与设备台账；
  - 样本：`ingest` 按 `(point, sampledAt, seq)` 幂等，返回 `accepted/skipped`；`pageSamples` 查询；
  - 看板：`saveBoard`、`pageBoards`、`boardData` 返回配置 + 指标最新样本；
  - 归档：`saveArchivePolicy`、`pageArchivePolicies`、`runArchive` 限定表清单、只做候选计数并更新执行信息。
- 端点：`/mes/equipment` 28 个、`/mes/collect` 12 个、内部 `/mes/internal/collect/{pointCode}` 1 个；
  业务端点均带 `@RequirePermission`，写操作带 `@AuditLog(targetType="mes_equipment" / "mes_collect")`。

## 4. 关键不变量与口径

| 不变量 | 实现方式 |
|---|---|
| 设备编码租户内唯一 | 保存前按 `(tenant, equipment_code)` 查重，冲突拒绝；为空自动生成 |
| 状态事件只追加 | `mes_eq_status_event` 无 `version`、不更新历史；`sourceEventId` 幂等防重复 |
| 故障阻断开工 | `gate` 对 `FAULT/OFFLINE` 与停用设备返回 `passed=false` |
| 保养项全部有结论才可验收 | 完工结果逐行 `项名=结论`，校验覆盖全部保养项、无多余、无重复 |
| 保养周期回写 | 验收后按 `lastDoneAt + cycleDays` 计算 `nextDueAt` |
| 维修状态不可跳转 | 动作端点按当前状态校验，非法流转拒绝 |
| 备件库存 ≥ 0 | 先查库存行，扣减后 `after.signum() < 0` 拒绝；库存行 `version` 乐观锁 |
| 备件流水只追加 | `mes_eq_spare_part_movement` 无 `version`，仅插入 |
| OEE 比率有界 | 三率分别截断到 [0,1]，OEE 取三率乘积并 6 位小数 |
| 样本幂等 | 唯一键 `(tenant_id, point_id, sampled_at, seq)`，重复上报计入 `skipped` |
| 归档可重跑 | `runArchive` 不物理删除，仅统计候选并更新执行时间/候选数 |

口径说明：

- OEE 默认公式：可用率 = 运行分钟 /（计划分钟 − 计划停机分钟），性能 = 理论产量 / 运行分钟
  （理论产量 = 总产量 × 理想节拍秒 / 60），质量 = 合格数 / 总产量，OEE = 三者乘积；
- 保养工单状态 `PLANNED → DUE → IN_PROGRESS → COMPLETED → ACCEPTED`，旁支 `OVERDUE`；
- 维修工单状态 `REPORTED → ASSIGNED → REPAIRING → VERIFIED → CLOSED`；
- 设备状态为事件流，当前状态取台账字段，历史通过事件表还原；
- 归档策略当前仅允许 `mes_cl_metric_sample`，保留天数与批次大小可配置。
