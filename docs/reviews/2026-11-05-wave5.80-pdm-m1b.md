### 2.2 后端

- `PdmBom` 增加派生来源字段；`PdmBomSaveRequest.view` 允许 `EBOM/PBOM/MBOM`。
- 新增支撑：
  - `PdmBomViews`：视图合法性与可派生判定；
  - `PdmBomExcelSupport`：纯 JDK 最小 XLSX 写入器（inlineStr + 数值单元格 + XML 转义）。
- 新增 DTO/VO：`PdmBomDeriveRequest`、`PdmBomDiffLineVO`、`PdmBomDiffVO`、`PdmBomExportRowVO`。
- `PdmBomServiceImpl`：
  - `create`：视图校验；PBOM/MBOM 缺省编号为 `BOM-{productCode}-{view}`；
  - `derive`：源必须 EBOM；草稿幂等；新版本升主版本；复制全部结构行；
  - `diff`：同产品校验、2000 行上限、路径并集、六类变更；

- `PdmBomController` 新增 `/diff`、`/diff/tasks`、`/diff/tasks/{id}`、`/{id}/derive`、`/{id}/export`。

## 3. 关键规则

| 规则 | 实现 |
|---|---|
| 仅 EBOM 可派生 | `derive` 检查 `source.view == EBOM` |
| 派生独立 | 派生 BOM 拥有独立 `bomNo/version/status` 与独立行，修改不影响源 EBOM |
| 派生幂等 | `sourceBomId + view` 最新为 `DRAFT` 时直接返回 |
| 派生升版 | 最新派生已发布/失效时，同 `bomNo` 升主版本并复制最新派生结构 |
| 对比范围 | 仅同一产品；按树路径（`1`、`1.1`）对齐 |
| 变更类型 | `ADDED / REMOVED / QTY_CHANGED / LOSS_CHANGED / UOM_CHANGED / PART_CHANGED` |
| 对比上限 | 同步任一 BOM 行数 > 2000 → 400；前端识别后创建异步任务并轮询（2 秒 × 30 次），异步执行不限行数 |
| 导出 | 深度优先，根路径为空；父子层级由路径体现；不引入第三方依赖 |
| 权限 | 派生用 `bom:add`；对比用 `bom:list`；导出用 940 |

## 5. 风险与遗留

| 风险 | 影响 | 处置 |
|---|---|---|
| 异步任务上限 | 超大 BOM 结果 JSON 可能较大、任务表持续增长 | 结果暂存 LONGTEXT；后续按 `create_time` 归档并考虑结果分页 |
| 派生不回写 EBOM | 符合边界，但 EBOM 变更后派生不会自动同步 | 后续可用「派生差异合并」或人工重建 |
| 导出未含供应商/价格 | M1B-5 仅补物料与库存只读，供应商/价格仍未纳入 | 后续如需报价列，再扩展 ERP 只读契约 |
| 去重已实现但需人工确认 | 历史重复零件仍存在 | 已提供候选与人工合并；不自动合并，避免误并 |
| 视图筛选依赖旧数据 | 存量 `pdm_bom.view` 若为空，列表按视图筛选会漏 | 迁移后核对存量数据，必要时补默认 `EBOM` |
| 前端导出按钮依赖 940 | 未执行权限迁移时用户看不到导出 | 上线前执行 `migration-5.80-pdm-bom-export.sql` |
