## 三、验收口径核对

| 验收项 | 落地方式 | 结论 |
|---|---|---|
| 导出与列表口径一致 | `page` 与 `export` 共用 `buildWrapper`（含 DENY 目录子树与 DENY 文档过滤） | 达成 |
| 中文在 Excel 直接可读 | 内容前置 UTF-8 BOM、`text/csv;charset=UTF-8` | 达成 |
| 字段含逗号/引号/换行不破坏列 | RFC 4180 转义 + 单测断言 | 达成 |
| 大数据量不拖垮响应 | 分批查询、5000 行上限、`X-Export-Truncated` 标记 | 达成 |
| 导出可审计 | `@AuditLog(type = EXPORT)` | 达成 |
| 同步失败可通知运维 | 告警端口 + 幂等键 `PDM:ALERT:{channel}:{key}` | 达成 |
| 告警不影响同步主流程 | 全部异常捕获只 `warn`；空接收人跳过；单测覆盖 | 达成 |

## 四、关键设计复核

1. **导出复用列表条件**：另写一套 SQL 会出现“列表看不到、导出却有”的越权面；共用方法后 ACL 语义只有一处实现。
2. **截断而非全量**：全量导出把内存和响应时间交给数据量；截断并显式标记，前端可以提示补充条件。
3. **告警按错误变化触发**：同一失败每次重试都发会变成噪声；只有新建失败或错误文本变化才通知。
4. **告警旁路化**：接收人未配置、消息服务不可达都不改变同步结果，避免把“通知失败”升级成“同步失败”。
5. **不做票据与 DEPT ACL**：两者都需要网关鉴权/头部改造，属跨服务工程；写入 §十九 遗留清单，避免在 PDM 内做半套能力。

## 五、遗留

| 级别 | 事项 | 建议 |
|---|---|---|
| 中 | 真实库未执行 `migration-5.80-pdm-doc-export.sql`，导出端点未起服冒烟 | 部署后复核权限 912，跑导出与截断路径 |
| 中 | `whale.pdm.alert.user-ids` 未配置 | 上线前确定运维接收人并验证 message 可达/不可达两条路径 |
| 低 | 导出仅覆盖当前查询条件的前 5000 行 | 业务确需全量时走异步导出任务，不放开同步上限 |
| 低 | 所属目录导出为目录 ID 而非名称 | 如需名称，补文件夹批量名称查询后再换列 |

外部依赖（CAD 插件、3D/Office 转换、ngram/OCR、下载票据、DEPT ACL、真实联调）见计划 §十九。
