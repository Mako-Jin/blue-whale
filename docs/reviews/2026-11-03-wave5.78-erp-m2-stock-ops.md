## 2. 变更清单

### 2.1 数据库迁移（`backend/whale-apps/whale-erp`）

- 新增 `V4__scm_stock_ops.sql`：4 张表
  - `erp_scm_transfer` / `erp_scm_transfer_line`（`uk_transfer_doc_no`、`uk_transfer_line`）；
  - `erp_scm_stocktake` / `erp_scm_stocktake_line`（`uk_stocktake_doc_no`、`uk_stocktake_line`）；
  - 数量 `DECIMAL(18,4)`、金额 `DECIMAL(18,2)`、单位成本 `DECIMAL(18,4)`；禁止 `DROP/TRUNCATE/DELETE`；
  - 末尾幂等写入科目 `1901`「待处理财产损溢」（ID 7021）。

> `V3__scm.sql` 已发布，调拨/盘点按版本顺序顺延为 `V4`。

### 2.2 后端代码（`com.bluewhale.erp.scm`，DDD 四层）

- `domain/model`：`Transfer` / `TransferLine`、`Stocktake` / `StocktakeLine`；`ScmStatus` 增
  `POSTED`、`SOURCE_TRANSFER`、`SOURCE_STOCKTAKE`；
- `domain/repository`：`TransferRepository`、`StocktakeRepository`（`page`/`count`/`findById`/`nextDocNo`/`insert`/`update`）；
- `application`：`TransferAppService` / `StocktakeAppService` 及实现、2 个命令、2 个视图；
- `infrastructure`：4 个实体、4 个 Mapper、2 个仓储实现（单号前缀 `TR-` / `ST-`）；
- `interfaces/controller`：`TransferController`（`/erp/scm/transfer`）、`StocktakeController`
  （`/erp/scm/stocktake`），`@RequirePermission` + `@AuditLog`；盘点过账从 `X-User-Id` 取操作人；
- `finance`：`AutoVoucherAppService` 增 `postStockVariance(AutoVoucherCommand)`；
  `ErpFinanceAccountProperties` 增 `stockVariance = "1901"`，`application.yml` 增
  `erp.finance.account.stock-variance`；
- `common`：`ErpErrorCode` 增 `TRANSFER_NOT_FOUND(40411)`、`STOCKTAKE_NOT_FOUND(40412)`、
  `TRANSFER_INVALID(40015)`、`TRANSFER_STATE_CONFLICT(40916)`、`STOCKTAKE_STATE_CONFLICT(40917)`；
- 关键规则：
  - 调拨必须双仓且不同、仓库启用、物料启用；空分录拒绝（`QUANTITY_INVALID`）；
  - 调拨出库按移动加权平均成本计价，库存不足拒绝（`NEGATIVE_STOCK`）；调入仓按
    `总成本 / 数量`（4 位 HALF_UP）入库，调拨本身不产生损益；
  - 盘点建单即快照账面数量与当前均价；过账按分录差异执行，盘盈无余额时新建余额；
  - 盘点净差异 `盘盈 − 盘亏` 非零时生成一张凭证，`sourceType=STOCKTAKE`、`sourceId=盘点单号` 幂等；
  - 已过账单据不可取消（`TRANSFER_STATE_CONFLICT` / `STOCKTAKE_STATE_CONFLICT`）。

### 2.3 权限脚本（`whale-service-auth-starter`）

## 4. 残余项与后续

| # | 残余 | 影响 | 建议 |
|---|---|---|---|
| R1 | 无调拨在途仓与跨组织结算价 | 只支持同组织双仓单步调拨 | 跨组织交易诉求明确后引入在途仓与结算价 |
| R2 | 无循环盘点计划与差异阈值 | 盘点按仓库一次性发起，差异不触发复盘 | 运营增强，按物料分类配置阈值与复盘流程 |
| R3 | 盘盈盘亏未做二次结转 | 差异停留在 1901，需手工结转到费用/营业外 | D5 科目映射表落地后增加期末自动结转 |
| R4 | 采购申请/退货、销售报价/退货未实现 | 采购/销售链路只有正向单 | 独立切片，退货接红字凭证与库存回写 |
| R5 | 批次/安全库存/呆滞、价格表、信用预占未实现 | 批次追溯、库存预警、价目表缺失 | M2 剩余 B，依赖 D6/D7/D8 定稿 |
| R6 | 财务扩展（资产/成本/预算/资金）未开始 | 财务只有核心 + 供应链自动记账 | 独立切片，D5 定稿后启动 |
| R7 | 实机冒烟未执行 | 网关路由与 auth 脚本未在真实库验证 | 部署环境执行迁移后按脚本末尾校验 SQL 核对 |
| R8 | 多币种仅存字段，未做汇率换算 | 外币单据金额按原币入账 | 承接 M0+M1 R2 |

## 5. 结论

M2 剩余 A 已把库存闭环补齐：调拨过账「调出仓出库 → 调入仓按成本入库」不产生损益；盘点建单快照账面、
过账按差异生成流水，并按净差异自动生成「待处理财产损溢」凭证，`sourceType + sourceId` 幂等。
两项均复用既有 SCM 四层与状态机，ArchUnit 无新增例外，前端两页已接入基座菜单与权限码。

建议下一步进入 M2 剩余 B 前先确认 D5（科目映射表）与 D6（是否引入批次/FIFO），避免调拨与盘点的
成本口径返工。
