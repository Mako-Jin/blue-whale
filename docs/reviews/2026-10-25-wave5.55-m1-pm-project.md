### 已修正问题项

1. **Checkstyle 8 处 Javadoc 缺失**：`DefaultWorkflowTemplate` 的两个 `record` 未写 `@param`，`JavadocType` 直接判错 → 补齐 5 + 3 个 `@param` 后复验 0 违规。
2. **无用常量**：`ProjectAppService` 初稿遗留 `ADMIN_FLAG` → 删除；`ProjectWorkflowAppService` 默认排序号误用 `FLAG_FALSE` 语义 → 改为显式 `0`。
3. **测试编译歧义**：`deleteById(any())` 在 `Serializable` / 实体重载间存在歧义 → 改为断言异常并移除该验证。
4. **模板跨租户风险**：计划 §3.4 设想的 `pm_status.project_id=0` 共享模板行会被租户插件隔离或跨租户读取 → 改为代码常量模板 + 建项目时复制项目私有配置，保持租户安全。
5. **权限编号收敛**：计划预留 172–190，实际 M1 用 172–186（流转新增/删除各占 1 个），M2 从 187 起编，已在迁移脚本与检查报告登记。
