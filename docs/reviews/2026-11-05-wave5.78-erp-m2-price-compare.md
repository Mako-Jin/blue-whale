## 2. 口径与边界

- **比价**：当前价取 `erp_scm_price_list` 中 `PURCHASE`、启用且有效期覆盖取价日期（缺省今天）的记录；成交价取有效采购订单分录，按供应商取单据日期最新一条。
- **最低价与差额**：仅在存在价格的供应商中标记 `lowest`；`gap = 当前价 − 最低价`，未配置价目时为 `null`。
- **趋势**：按自然月分组；均价为数量加权（`Σ(单价 × 数量) / Σ数量`），数量合计为 0 时退化为简单平均，保留 4 位 `HALF_UP`；统计月数默认 6、限 1–24，越界抛 `PRICE_INVALID`。
- **不新增表**：本片为纯查询计算，仅新增权限脚本；`bluewhale_erp` 仍 68 表。
- **性能边界**：当前按物料加载全量有效分录后在内存分组，数据量增长后应改为 SQL 聚合（按物料 + 月份）。
