## 2. 关键实现口径

### 2.1 系列与集数

- 系列固定 `contentType=VIDEO`，创建即为 `DRAFT`、`episodeCount=0`；运营可编辑标题 / 简介 / 分类 / 创作者 / 封面 / 排序，`coverFileId=0` 清除封面。
- 集数唯一在应用层校验（`existsSeriesEpisode(seriesId, episodeNo, excludeContentId)`），不建 DB 唯一键，避免 `@TableLogic` 逻辑删除数据占用唯一索引。
- 更新内容时使用「排除自身」的冲突判断，因此同一内容重复提交同一集数是幂等的；`seriesId<=0` 会同时清零 `episodeNo`。
- 非视频内容携带 `seriesId` 一律 `40404`（不泄露系列存在性）；系列不存在同样 `40404`。
- `vd_series.episode_count` 由 `ContentRepository.countPublishedEpisodes` 计算（仅 `PUBLISHED + PUBLIC`），在内容创建 / 编辑 / 删除 / 发布 / 下架 / 版权下架后按系列刷新；`updateEpisodeCount` 只更新计数字段，避免并发覆盖其他列。
- 存在已发布集数的系列禁止删除 → `40901`；集数全部删除后计数归零，系列可删除。

### 2.2 用户侧契约

- 新增 `GET /video/series/page`（`sys:video:browse`）：仅返回已上架系列，忽略客户端 `publishState` 过滤，并补充 `creatorName`；与运营分页共用 `SeriesQueryCommand`。
- `GET /video/series/{id}`：未上架 / 不存在统一 `40404`；仅返回已发布公开集数，`episodeCount` 以实际列表长度覆盖，避免计数与可见集不一致。
- `GET /video/series/{id}/cover`：已上架但无封面返回 `404`（`ErrorCode.NOT_FOUND`）；未上架返回 `40404`；图片代理沿用 `private, max-age=600` + `nosniff` + `Accept-Ranges`。
- 公开 VO（`PublicContentView` / `SeriesView`）不暴露任何 `fileId`，封面走代理地址、播放走票据 + `/video/stream/{id}`。
- auth 迁移 `migration-5.77-video.sql` 的 314 权限 GET 路径补充 `/video/series/page`，与新增端点同步。

### 2.3 前端（`frontend/platform-apps/whale-video`）

- `api/video.ts` 增加 `SeriesView / SeriesDetailView`、`fetchSeriesPage / fetchSeriesDetail / buildSeriesCoverUrl`；`ContentSaveInput` 增加 `seriesId / episodeNo`。
- `VideosPage`：系列精选（仅已上架）+ 视频分页（关键词 / 分类 / 系列集数 / 可播放标记 / 分页）；`VideoDetailPage`：播放器 + 简介 + 所属系列集数入口；`SeriesDetailPage`：封面 / 集数网格 / 空态与 403 / 404 处理。

- `UploadPage` / `MinePage`：视频类型展示「所属系列 + 集数」，选择系列后集数必填；编辑回填时将 `0` 转为未选择。

## 4. 设计决策与本次修正

| 项 | 决策 / 处理 |
|---|---|
| 用户侧缺少系列选择数据源 | 原契约仅有 `GET /video/series/{id}`，上传 / 编辑无法选择系列；新增 `GET /video/series/page`（仅已上架、补创作者昵称），并同步 auth 314 路径，`SeriesQuery` Javadoc 本就约定「运营列表 / 用户侧系列选择共用」 |
| 集数唯一未建 DB 唯一索引 | 逻辑删除下历史行仍占索引位，改由应用层 `existsSeriesEpisode` 校验；同一内容更新时排除自身保证幂等 |
| 系列详情 `episodeCount` | 以实际已发布公开集数列表长度覆盖数据库计数，避免「计数含私密 / 已下架集」造成用户侧不一致 |
| 系列无独立缓存 | 上下架后仅依赖 `vd_series.publish_state` 查询，用户侧即时生效；内容上下架通过 `evict` 失效可播 / 首页 / feed 首屏 |
| 前端播放器新增 `fit` / 全屏 / 快捷键 | 未新增 `volume` state（直接操作 `video.volume`），避免未读状态触发 lint；快捷键在 `INPUT / TEXTAREA / SELECT / contentEditable` 内不拦截 |
| admin `Tag` 不支持 `title` | 版权状态提示改为 `Tooltip` 包裹，消除 `tsc` 报错 |
