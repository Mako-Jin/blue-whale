## 4. 设计决策与偏差

1. **SSE 用 POST + Bearer 头**：`EventSource` 无法携带 Authorization，网关 JWT 仅从请求头解析；采用共享 http 客户端 `streamSse`（fetch 流式读取 + JSON body + 401 续期重放），不改网关、不引入 WS ticket 通道。
2. **聚合复用而非重算**：生产/质量域直接调用既有看板服务，杜绝两套口径；设备/人员为跨上下文只读查询（仅 mapper 读取，无写路径），与 ArchUnit 分层规则兼容。
3. **无新表**：看板为实时聚合，不落地快照表；保留策略在运维手册中说明沿用各模块既有策略，物理归档仍待 D14。
4. **dev 环境 admin 口令重置**：冒烟需要 admin 登录，本机 dev 库 admin 口令不可恢复，已重置为 `BwMesM5b@2026`（仅本地开发库，生产凭据不受影响）。
