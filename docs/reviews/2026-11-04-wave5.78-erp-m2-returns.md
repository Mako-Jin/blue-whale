## 2. 关键实现口径

| 项 | 口径 |
|---|---|
| 可退数量 | 按源订单行累计（非已取消退货单），`本次 + 已退 ≤ 已收/已发`；建单与过账各校验一次 |
| 采购退货出库 | 按订单单价 `outboundAt`，库存数量与金额同步扣减，成本金额 = 应付冲减金额 |
| 销售退货入库 | 按过账前当前移动加权均价入库；无余额时成本为 0 并跳过成本分录 |
| 往来冲减 | `remaining > 0` 的台账按 `docDate, id` 升序分摊；不足整单拒绝 |
| 凭证 | 采购：借应付/贷存货；销售：借收入/贷应收 + 借存货/贷成本；`sourceType+sourceId` 幂等 |
| 幂等 | 过账状态守卫；库存流水来源键；凭证唯一键；冲减随过账一次性完成 |

## 4. 偏差与后续

1. 应付/应收按往来方级未核销台账分摊，未精确回溯到原收货/发货单（现有台账未记录收货单号）。
2. 销售退货成本取当前移动加权均价，未保存发货批次成本快照。
3. 退货单为单人 `DRAFT→POSTED` 闭环，未接 OA 审批流。
4. 采购申请、销售报价、批次/安全库存/呆滞、价格表/信用预占、财务扩展仍待排期。
5. 修复 `AlertAppServiceImplTest` 对固定日期 `20261104` 的依赖，改为按当天日期构造，避免跨日失败。
