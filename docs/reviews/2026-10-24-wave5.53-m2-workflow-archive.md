## 三、A 类 —— 协议与接口安全

| 检查项 | 结论 |
|---|---|
| 内网接口暴露 | workflow/form/file 新增接口全部位于 `/workflow/internal/**`、`/form/internal/**`、`/file/internal/**`，网关 `internal-deny` 已覆盖并返回 403；服务间以 RestClient 直连，不经网关 |
| 权限注解 | 内网接口刻意不加 `@RequirePermission`（外部不可达）；档案同步触发 `sys:archive:sync:run`、状态查询 `sys:archive:item:list`，均经网关权限码头判定 |
| 越权读取表单 | 表单内网接口按配置租户（`X-Tenant-Id`）读取，避免跨租户取数；租户由部署配置固定，不由请求方任意指定 |
| 输入校验 | 游标时间用 `@DateTimeFormat(ISO)` 解析；分页 `size` 服务端收敛 `[1,200]`、`current >= 1`；路径 ID 为 `Long`，非法值由框架 400 |
| 响应面收敛 | 跨服务 DTO 均 `@JsonIgnoreProperties(ignoreUnknown = true)`，仅取契约字段；`RemoteHttpSupport` 统一校验 `code=0` 并把网络/结构异常转为 `BizException(500, 动作 + 原因)`，不泄露堆栈 |
| 文件内容 | `/file/internal/{id}/content` 附 `X-Content-Type-Options: nosniff` 与 `attachment` 处置，防 MIME 嗅探 |

## 四、B 类 —— 代码漏洞与健壮性

| 检查项 | 结论 |
|---|---|
| 幂等（同步） | `archive_item (source_type, source_id)` 唯一索引 + 同步前查台账/条目双保险；`archive_source_record` 成功即跳过；`DuplicateKeyException` 视为已同步 |
| 幂等（游标） | `archive_sync_state` 按 `name` 唯一持久化水位，重启不重扫；同轮用 `AtomicBoolean` 拒绝并发触发 |
| 失败重试 | 失败写台账 `sync_status=2, retry_count+1, last_error`（截断 1000）；下一轮按 `retry_count < max_attempts` 重扫；达到上限不再拉取 |
| 事务边界 | 条目/文件引用/台账在同一事务（`ArchiveItemStore`，独立 Bean，避免自调用失效）；上传与锁定在事务外，失败留台账重试 |
| 不可变与防误删 | 快照与附件统一 `POST /file/internal/{id}/lock` → `file_info.status=2`；锁定文件 `delete` 抛参数错误；解锁幂等 |
| 快照可复算 | 键顺序固定、时间统一 ISO-8601 字符串，SHA-256 由 `MessageDigest` 计算；单测验证同输入两次生成字节一致 |
| 附件提取 | 递归 `attachment`（数字/字符串/对象三形态）与 `subtable` 子字段，`LinkedHashSet` 去重，过滤非法/非正 ID；不存在附件告警跳过 |
| 资源与异常 | RestClient 显式连接 5s / 读取 60s 超时，避免同步线程堆积；单条失败不影响整轮 |
| 敏感信息 | 日志仅输出 `sourceId / retryCount / 截断错误信息`，不含表单值或文件内容 |

## 五、C 类 —— 圈复杂度与结构

- `ArchiveSyncService#archive` 为最复杂方法（约 15 行主体，已拆出 `buildItem` / `buildFileRefs` / `lockFiles` / `loadForm` / `findRule` / `buildCategoryPath` 等私有方法），单方法分支数 < 10，远低于 15 阈值。
- `ArchiveSyncService#runOnce` 仅做编排与结果汇总，单轮计数由内部 `SyncCounters` 承担，避免 `long[]` 魔法下标。
- Controller 仅做参数接收与结果包装；跨服务访问集中在 `client` 包，转换集中在 `support` 包，无跨层直连。

## 六、D 类 —— 魔法值

- 实例状态、条目状态、同步状态、来源类型、文件角色、密级、字段类型、游标名、摘要长度、快照 MIME 与后缀全部收敛至 `ArchiveConstants`。
- 分页上限、同步页大小、重试次数、重试批量、超时均为具名常量或配置项（`whale.archive.sync/integration`）。
- 时间格式统一使用 `DateTimeFormatter.ISO_LOCAL_DATE_TIME` / 具名 `DateTimeFormatter`，无散落格式串。
