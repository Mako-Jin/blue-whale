## 2. 关键口径

1. **状态机**：采购申请 `DRAFT → APPROVED → CONVERTED`，销售报价 `DRAFT → ACCEPTED → CONVERTED`；`CONVERTED` 拒绝取消，`DRAFT/APPROVED/ACCEPTED` 可取消。
2. **转单**：先校验状态，再调用既有 `PurchaseAppService.create` / `SalesAppService.create` 生成草稿订单（`docDate = 今天`，`expectedDate = requiredDate` / `deliveryDate = validUntil`），成功后回写 `convertedOrderNo` 并置 `CONVERTED`；重复转单抛 `ORDER_STATE_CONFLICT`。
3. **金额**：行金额 = 单价 × 数量（2 位 HALF_UP），头金额为行合计；数量与单价必须为正。
4. **主数据**：供应商、客户、物料取启用状态快照，停用抛 `SUPPLIER_INVALID` / `CUSTOMER_INVALID` / `ITEM_INVALID`。
5. **无副作用**：转单只生成草稿订单，不触发库存、应收应付与凭证，与既有订单审核后的记账链路解耦。
