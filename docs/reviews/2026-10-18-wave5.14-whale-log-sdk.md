## 未通过项与修复记录

本波共 **3 项** 在自检中被发现并当轮修复（均登记于 devlog §三）：

1. **[#72，P2] `maskText` 掩码顺序缺陷** — `Bearer <token>` 先被「凭据键值对」规则（含 `authorization` 分支）整体掩码为 `******`，导致 Bearer 专项规则失效，且残留裸 token 片段。**修复**：`Bearer` 规则前置于凭据规则，并为凭据值的值部分加 `(?!Bearer\b)` 负向断言；冒烟断言 3 复验通过。
2. **[#73，P2] 退避定时器被 `unref` 导致 Node 提前退出** — 重试等待的 `setTimeout` 被 `unref`，事件循环随即为空，`await` 永不恢复、冒烟**静默假通过**（退出码 0 但无输出）。**修复**：`delay` 去掉 `unref`（仅长驻的 flush 间隔定时器保留 `unref`）；重跑冒烟输出 `smoke passed: 30 assertions`。
3. **[#74，P2] 新增 `.mjs` 与 console 包装模块触发 ESLint 报错** — 冒烟脚本 `console`/`process` 触发 `no-undef` 4 error，`console.ts` 触发 `no-console` 2 warning。**修复**：`eslint.config.js` 增 `**/*.mjs` Node globals 块；`console.ts` 文件级 `eslint-disable no-console` 并注明理由；复验 `eslint .` → 0 error。
