### 回调处理

- 新增 `ct_esign_callback` 实体/Mapper、`EsignCallbackPayload`、`EsignCallbackService(Impl)`、`EsignCallbackController`（`POST /contract/sign/callback/{provider}`，`@RequestBody String rawBody` 保留原始字节用于验签）+ `client/WorkflowInternalClient`（透传 `X-Tenant-Id`，校验 `code==0`）。
- 流程：验签失败/超窗 → `FORBIDDEN`（403 信封）并落审计；payload 校验 `providerEventId/action`；已 `PROCESSED` 幂等返回；`prepareCallback` 依赖唯一键，`DuplicateKeyException` 兜底；`transactionTemplate` 内完成证据落库 + 任务/合同状态 + 推进工作流；异常标记 `FAILED + error_msg` 后抛出。
- SIGN：定位任务（`signTaskId` 或 `provider + providerTaskId`）并校验渠道一致 → 优先下载签章件，失败/不支持时使用回调 `signedSha256`（缺失用 `payloadHash`）→ `EsignHashUtils.chain` 生成 `chain_hash` → 写 `ct_sign_record`（`algorithm={PROVIDER}-REMOTE`）→ 任务 `SIGNED`，全部签完合同 `SIGNED` 否则 `SIGNING` → `advanceWorkflow` 完成关联流程任务。
- REFUSE：任务 `REFUSED` + 原因，合同停留 `SIGNING`，关联流程任务按 `REJECT` 推进。

## 五、风险与观察

- **合规边界**：`Esignbao/Fadada/Ssq` 当前为 HMAC 骨架实现，`createTask` 走本地模板生成签署链接，未调用真实平台 API；生产接入需替换为平台 RSA/SM2 签名、实名意愿认证与持牌 CA/TSA 时间戳（设计稿 R1/R3）。
- **签章件兜底**：非 local 渠道无法下载签章件时，以回调携带的 `signedSha256`（或回调 `payloadHash`）入链；证据完整但不等价于原始文件核验，接入真实平台后应走 `downloadSignedFile`。
- **回调补偿**：乱序/丢失依赖人工重放；`queryTask` 定时补偿（设计稿 R5）留待后续迭代。
- **权限授予**：迁移不写 `sys_role_permission`，业务角色需在角色管理勾选 232 与 `sys:contract:evidence:read`。
- **归档衔接**：`archive` 仍为合同侧状态流转，未新增 `whale-archive` 内部快照接口。
