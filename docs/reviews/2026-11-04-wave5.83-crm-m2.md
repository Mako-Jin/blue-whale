## 2. 变更清单

### 2.1 数据库迁移（`whale-backend/whale-apps/whale-crm/src/main/resources/db/migration`）

- 新增 `V4__sales_process.sql`：
  - `crm_lead`：编号 / 名称 / 状态 / 来源 / 行业 / 地区 / 联系人 / 负责人 / 部门 / 转化结果 / 无效原因，唯一键 `uk_crm_lead_no`，索引负责人、状态、归一化电话 / 邮箱 / 名称；
  - `crm_lead_activity`：线索活动（渠道 / 内容 / 结果 / 下次动作 / 下次时间 / 操作人）；
  - `crm_opportunity_stage_history`：阶段历史（from/to、金额、概率、输单原因、操作人、变更时间）；
  - `crm_opportunity` 守卫式补列：`probability`、`source`、`competitor`、`next_action_at`、`stage_entered_at`、`version`，索引 `idx_crm_opportunity_stage_owner`；
  - 全部增列用 `information_schema.COLUMNS` + `PREPARE STMT FROM @ddl`；索引用 `information_schema.STATISTICS` 守卫；无 `INSERT INTO CRM_` 种子数据。

### 2.2 后端代码（`com.bluewhale.crm.sales`）

- `domain`：`LeadStatus`、`Lead`、`LeadQuery`、`LeadActivity`、`OpportunityStage`、`Opportunity`、`OpportunityQuery`、`OpportunityStageHistory`；四个仓储端口。
- `application`：8 个命令、7 个视图、`LeadAppService` / `OpportunityAppService` 接口与实现。
- `infrastructure`：`LeadEntity` / `LeadActivityEntity` / `SalesOpportunityEntity`（`@Version`）/ `OpportunityStageHistoryEntity` + 四个 Mapper + 四个仓储实现。
- `interfaces`：`LeadController`（`/crm/lead`）、`OpportunityController`（`/crm/opportunity`），全部挂 `@RequirePermission`，写接口挂 `@AuditLog`。
- `common`：`CrmErrorCode` 补 41021–41030；`CrmPermissions` 补 9 个线索/商机权限常量。

### 2.3 权限脚本（`whale-backend/whale-services/whale-service-auth/whale-service-auth-starter/src/main/resources/db/migration-5.84-crm-sales.sql`）

- 权限 1840–1849：`sys:crm:lead:list/create/update/assign/invalid/convert`、`sys:crm:opportunity:list/create/update/stage`；
- 授权：`crm_admin` / `tenant_admin` / `crm_sales_manager` 全量；`crm_sales` 除 `assign`；`crm_marketing` 1840–1842、1846；`crm_service` / `crm_analyst` 仅 1840、1846；
- 全部 `INSERT ... SELECT ... WHERE NOT EXISTS`，授权 ID 为业务键 MD5 前 15 位；菜单 421–426 不登记。

### 2.4 测试

- 新增 `LeadAppServiceImplTest`（12 项）：编号生成、查重拒绝 / 确认放行、数据范围、状态推进、无效原因、转化建客户 + 商机 + 历史、已转化幂等、并发失败、活动推进、门禁、活动分页。
- 新增 `OpportunityAppServiceImplTest`（13 项）：客户必填、初始 CONTACT / 10%、概率区间、已关闭拒编辑、乐观锁冲突、合法 / 非法阶段流转、WON 金额、LOST 原因、数据范围、漏斗聚合、门禁。
- `CrmFlywayMigrationScriptTest` 新增 V4 断言：三表集合、无业务种子、守卫写法、`uk_crm_lead_no`。

## 4. 风险与偏差

| # | 项 | 现状 | 处理 |
|---|---|---|---|
| 1 | 数据范围 | 仍为角色判定（全量角色 vs 本人），未接 auth 部门树 | 与 M1 一致；auth 内网 `data-scope` 就绪后统一替换 |
| 2 | 线索分配 | 仅手工分配，要求全量数据范围 | 规则引擎后置；越权返回 `DATA_SCOPE_DENIED` |
| 3 | 漏斗转化率 | 首阶段固定 100%，上一阶段为 0 时按 100% 处理 | 与计划口径一致；M6 指标字典时复核边界 |
| 4 | 阶段停留时长 | 仅落 `changed_at`，未计算平均停留 | 避免与 M6 重复定义，留待分析口径统一 |
| 5 | 报价 / 预测 / 目标 | 未实现 | 明确列入 M2 增量；不占用 1845–1859 |
| 6 | 转化并发 | `markConverted` 条件更新失败时抛 `41024`，事务回滚已建客户 / 商机 | 单测覆盖；未做真实并发压测 |
