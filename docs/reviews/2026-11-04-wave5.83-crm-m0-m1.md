## 2. 变更清单

### 2.1 数据库迁移（`whale-backend/whale-apps/whale-crm/src/main/resources/db/migration`）

- `V2__crm_foundation.sql`
  - `crm_customer`：`short_name`、`website`、`scale`、`tax_no`、`province`、`city`、`region`、
    `normalized_name`、`normalized_domain`、`normalized_tax_no`、`version`、`pool_status`、`pool_at`、
    `last_follow_up_at`；
  - `crm_contact`：`wechat`、`decision_role`、`is_decision_maker`、`normalized_phone`、`normalized_email`、`version`；
  - `crm_follow_up`：`result`、`next_action`；
  - 增列统一用 `information_schema.COLUMNS` 存在性守卫 + `PREPARE` 动态 SQL（MySQL 8 不支持 `ADD COLUMN IF NOT EXISTS`）；
  - 守卫索引：`idx_crm_customer_norm_name` / `norm_tax` / `norm_domain` / `pool`、`idx_crm_contact_norm_phone` / `norm_email`；
  - 阶段口径修正：`UPDATE crm_opportunity SET stage='CONTACT' WHERE stage='LEAD'`；
  - 新建集成四表：`crm_common_outbox`、`crm_int_sync_log`、`crm_external_ref`、`crm_idempotency`。
- `V3__customer_profile.sql`
  - `crm_customer_address`、`crm_customer_profile`（`decision_chain TEXT`、`sensitive_remark`、`version`，
    唯一键 `uk_crm_profile_customer (tenant_id, customer_id)`）、`crm_customer_pool_rule`、`crm_customer_owner_log`。
- 全部脚本无 `DROP` / `TRUNCATE` / `DELETE`，无业务种子数据。

### 2.2 后端代码（`com.bluewhale.crm`）

- `common`：`CrmActor`（角色、数据范围、`requireUserId`）、`CrmMasking`（手机/邮箱/税号/微信/备注）、
  `CrmPermissions`（权限码常量）、`CrmErrorCode`（41000–41020）。
- `customer.domain`：枚举 `CustomerStatus` / `CustomerLevel` / `PoolStatus` / `FollowUpChannel`；
  聚合与值对象 `Customer` / `Contact` / `CustomerAddress` / `CustomerProfile` / `DecisionChainEntry` /
  `CustomerPoolRule` / `CustomerOwnerLog` / `CustomerFollowUp` / `CustomerQuery` / `DuplicateCandidate` /
  `CustomerNormalizer` / `CustomerOpportunitySummary`；端口 `CustomerOpportunityPort`；六个仓储接口。
- `customer.application`：9 个命令、11 个视图、3 个服务接口 + 实现
  （`CustomerAppServiceImpl`、`CustomerPoolAppServiceImpl`、`CustomerFollowUpAppServiceImpl`）。
- `customer.infrastructure`：7 个业务实体 + 7 个 Mapper + 6 个仓储实现（原子 `claim` / `release` / `updateOwner`、
  归一化硬冲突查询、回收候选查询）。
- `integration.infrastructure`：`OpportunityEntity` / Mapper / `CustomerOpportunityAdapter`（实现商机摘要端口）。
- `customer.interfaces`：`CustomerController`、`CustomerContactController`、`CustomerPoolController`、
  `CustomerFollowUpController`；`interfaces.support.CrmActorContext`（网关身份头 → `CrmActor`）+
  `CustomerPageParams` / `PageParams`；`CrmPoolRecycleJob`（`whale.crm.pool-recycle-enabled=true` 才装配）。
- 配置：`CrmProperties`（门禁默认 `true`、客户编码前缀、跟进分页上限、合同引用开关、默认等级 `C`、
  回收开关 / 表达式 / 批大小）；`WhaleCrmApplication` 加 `@EnableScheduling`；`/crm/meta` 改为 M0/M1 口径。

### 2.3 权限脚本（`whale-backend/whale-services/whale-service-auth/whale-service-auth-starter/src/main/resources/db`）

- 新增 `migration-5.83-crm.sql`：
  - 权限 `1800 sys:crm:sensitive:view`；`1810`–`1830` 客户 / 联系人 / 地址 / 画像 / 跟进 / 公海 22 项；
  - 菜单 413–420 **不登记**（前端未交付）；
  - 角色 `25128 crm_sales` / `25129 crm_sales_manager` / `25130 crm_service` / `25131 crm_marketing` / `25132 crm_analyst`；
  - 授权：管理员 / 主管 `1800 + 1810–1830`；销售 `1810,1811,1812,1814–1826`；客服 `1810,1816,1818,1820,1822,1823`；
    市场 `1810,1815,1820,1822`；分析 `1810,1820,1822,1824`；
  - 业务租户按 `MD5(tenant:role)` / `MD5(role:permission)` 前 15 位复制，全部 `NOT EXISTS` 幂等；
  - 1800–1850 区间经全量脚本核对未被占用。

## 4. 遗留与风险

| 项 | 说明 | 处理 |
|---|---|---|
| 数据范围降级 | 仅角色判定（全量 / 本人），无部门树与授权范围 | auth 内网 `data-scope` 就绪后替换 `CrmActor.allDataScope()` |
| 集成底座未联通 | 合同 / ERP / 工作流 / 消息 / 文件 / 文档无客户端；360 中显式声明不可用 | M3 起按里程碑接入，outbox 四表可直接复用 |
| 客户合并/导入导出 | 未实现，`MERGED` 只读态已就绪 | 后续增量（含引用重写、CSV 预检、异步导出） |
| 前端与菜单 | 8113 未创建，菜单 413–420 未登记 | 前端交付时同步登记菜单与按钮权限 |
| 自动回收默认关闭 | `whale.crm.pool-recycle-enabled=false` | 规则灰度验证后按租户打开 |
| 审计参数体积 | 18 个写接口已加 `@AuditLog`；客户/地址/公海命令仍记录参数 | 与审计 MQ 汇聚联调后复核脱敏与体积，必要时关闭自由文本参数 |
| 真实库迁移 | Flyway V1–V3 仅静态校验，未在 MySQL 实库执行 | 联调环境执行并按脚本末尾核对表/索引/权限 |
| 唯一索引与软删除 | 客户编码、画像等唯一键含 `deleted` 语义需实库确认 | 联调阶段验证“删除后重建同名客户”路径 |
