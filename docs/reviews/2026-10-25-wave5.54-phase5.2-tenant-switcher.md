# Wave 5.54 Phase 5.2 检查报告：admin 一人多租户切换器

> 日期：2026-10-25 ｜ 范围：`whale-frontend/admin`（`api/auth.ts`、`layouts/AdminLayout.tsx`）｜ 依据：[code-review-checklist.md](../checklists/code-review-checklist.md)

## 一、变更清单

| 文件 | 变更 |
|---|---|
| `whale-frontend/admin/src/api/auth.ts` | 新增 `MyTenantVO`、`listMyTenants()`、`switchTenant(tenantId, tenantCode)` |

## 二、检查结果

| 类别 | 检查项 | 结论 | 证据 |
|---|---|---|---|
| 协议安全 | 切换请求不携带客户端 `userId` / 角色 | 通过 | 请求体仅 `tenantId` + 当前 `refreshToken`；身份由后端 `SecurityContext` 解析 |
| 协议安全 | `refreshToken` 不落日志、失败不落盘 | 通过 | 仅通过请求体传递；`saveLogin` 在接口成功后调用 |
| 协议安全 | 切换后旧令牌失效 | 通过（后端已有） | 后端 `AuthService#switchTenant` 双写黑名单；前端重载后只持有新令牌 |
| 代码漏洞 | 组件卸载后的异步状态写入 | 通过 | `useEffect` 以 `cancelled` 标志守卫 |
| 代码漏洞 | 重复点击 / 切换中并发 | 通过 | `switching` 同时控制 `disabled` 与 `loading` |
| 代码漏洞 | 切换失败后的登录态 | 通过 | `catch` 仅提示并复位 `switching`，不清令牌 |
| 代码漏洞 | 列表加载失败的影响面 | 通过 | 静默回退原租户 `Tag`，不阻断页面 |
| 圈复杂度 | 新增函数 | 通过 | `handleSwitchTenant` 分支 3（查找、当前项、成功/失败），无需拆分 |
| 魔法值 | 常量与文案 | 通过 | 无新增数值常量；展示文案为中文（与 admin 现有页面一致） |
| 规范 | 前端 `console` | 通过 | 未使用 `console` |
| 规范 | TypeScript 严格模式 | 通过 | `tsc -b` EXIT=0 |
| 规范 | ESLint | 通过 | `eslint src --max-warnings 0` EXIT=0 |
