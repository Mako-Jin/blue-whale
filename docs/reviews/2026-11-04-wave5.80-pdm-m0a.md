### 2.2 后端（`com.bluewhale.pdm.document`）

- 实体/Mapper：`PdmDocFolder`、`PdmDocDocument`、`PdmDocVersion` + 3 个 `BaseMapper`；
- DTO/VO/转换：目录与文档保存请求、分页查询、树形目录、文档/版本视图；`PdmConverter` 新增 5 个映射；
- 支撑类：`PdmDocVersionNo`（解析/递增/发布目标/排序值）、`PdmDocRoles`、`PdmDocRequestContext`、
  `PdmDocDownload`、`PdmDocUploadFile`；
- 客户端：`PdmDocFileClient` 通过 `DiscoveryClient` + `InternalTokenSupport` 调用
  `/file/internal/upload`、`/file/internal/{id}/content`，错误码解包；
- 服务：`PdmDocFolderService`（树/建/改/删/子树/**默认目录**）、`PdmDocDocumentService`

- 控制器：`PdmDocFolderController`、`PdmDocDocumentController`，全部 `@RequirePermission`，写操作 `@AuditLog`。

### 2.3 前端

- `whale-pdm` 改为 `BrowserRouter`（base `/pdm`）：`/document` 默认、`/product` 保留；
- 新增 `api/document.ts`、`pages/document/{index,DocumentForm,UploadModal,FolderModal,VersionDrawer,utils}`、

## 3. 关键规则与不变量

| 规则 | 实现 |
|---|---|
| 版本唯一 | `uk_doc_version_no` + `assertVersionNoUnique`；发布目标冲突抛 409 |
| 已发布不可变 | 更新/删除只作用于文档元数据与草稿；存在 `RELEASED` 版本时删除文档被 409 拒绝 |
| 发布推进 | `V0.n → V1.0`；其他 `RELEASED` 同文档版本置 `OBSOLETE`；`document.currentVersionId/status` 同步 |
| 检入释放锁 | `checkIn` 仅限检出人；成功后清空 `checkedOutBy/checkedOutTime` 并生成 `V*.n+1` 草稿 |
| 回滚不改历史 | 回滚复制源版本文件元数据与校验和，新建草稿并回写 `latestVersion`；源版本状态不变 |
| 目录防环 | 移动时校验目标父目录 `path` 不以自身 `path` 开头；递归重写子树 `path` |
| 目录移动一致性 | 删除要求无子目录且无文档；同名同父级被拒 |
| 编号生成 | 最多 5 次随机候选并查重，仍冲突则系统异常提示重试 |
| 租户隔离 | 依赖 MyBatis 租户行插件；跨租户按 ID 查询返回“文档不存在”（404 语义） |
| 审计脱敏 | 审计只记录操作与目标 ID，不落文件正文/图纸内容；下载端点记录下载动作 |

## 5. 风险与遗留

| 风险 | 影响 | 处置 |
|---|---|---|
| ACL 未启用 | 文档读/下载仅靠租户内功能权限，写操作靠属主/管理员范围，无法按文件夹/个人精细授权 | M0-B 实现文件夹继承 + 显式 DENY 优先；接口签名预留 `canManage` |
| 下载无短时票据 | 下载依赖登录态 + 功能权限；未绑定文档/版本的临时凭证 | M0-B 引入短时票据或一次性 token，替换直接代理 |
| 下载代理大文件内存占用 | 当前 `byte[]` 全量读取，超大图纸可能占用堆内存 | M0-B/预览阶段改流式 `Resource` + Range 透传 |
| 预览任务缺失 | 前端无法在线查看 DWG/PDF | M0-B 建预览任务表与转换适配器 |
| 删除文档为物理/逻辑混合 | 版本与文档删除依赖 MyBatis 逻辑删除；历史文件字节未清理 | 增加文件清理补偿任务（按 `fileId` 引用计数） |
| 前端打包体积 | antd + 页面一次性打入 1.25MB（gzip 397KB） | 后续按路由懒加载与 manualChunks 优化 |
