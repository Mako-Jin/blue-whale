## 2. 变更清单

### 2.1 数据库迁移

- `whale-backend/whale-apps/whale-pdm/src/main/resources/db/migration/V4__part_bom.sql`
  - 通过 `information_schema.COLUMNS` 逐列幂等扩展 `pdm_product` 的 7 个字段；
  - `CREATE TABLE IF NOT EXISTS`：`pdm_part_category`（`uk_part_category_code`、`uk_part_category_name`、`idx_part_category_path`）、
    `pdm_bom`（`uk_bom_no_version`、`idx_bom_product`）、`pdm_bom_line`（`uk_bom_line_no`、`uk_bom_line_child`）、
    `pdm_bom_release`（`uk_bom_release`、`idx_bom_release_no`）；
  - 租户 1 种子分类 `STD/COMMON/RAW`（`INSERT IGNORE`）；无 `DROP/TRUNCATE/DELETE`。
- `whale-backend/whale-services/whale-service-auth/whale-service-auth-starter/src/main/resources/db/migration-5.80-pdm-part.sql`
  - 权限 930–939：`sys:pdm:part:list/add/edit/delete/category:manage`、`sys:pdm:bom:list/add/edit/delete/release`；
  - 菜单 185 零件库 `/pdm/part`、186 BOM 结构 `/pdm/bom`；
  - 角色 21104 `pdm_engineer` + 业务租户 MD5 复制；全部 `NOT EXISTS` 幂等。

## 3. 关键规则与不变量

| 规则 | 实现 |
|---|---|
| 零件默认值 | `partType=PART`、`uom=PCS`、`sourceType=UNIQUE`；空字符串同样归一 |
| 分类唯一 | 全局 `code` 唯一 + 同级 `name` 唯一；移动时禁止把祖先挂到自身后代 |
| 分类删除保护 | 存在子分类或被零件引用时拒绝 |
| 零件删除保护 | 作为 BOM 根产品或任一 BOM 行的父/子件时拒绝 |
| BOM 版本 | `V1.0 → V2.0`；同一 `bomNo` 多版本共存，至多一个 `RELEASED` |
| 草稿限定 | 仅 `DRAFT` 可增改删行、可删除 BOM |
| 装配约束 | 父件必须为 `PRODUCT/ASSEMBLY`；子件必须启用 |
| 环检测 | 父链回溯命中子件（含自身）返回 `BOM_CYCLE_DETECTED:` |
| 行唯一 | 同父同级 `lineNo` 唯一、同父子件唯一 |
| 发布 | 至少 1 行；冻结快照；同家族旧 `RELEASED` 置 `OBSOLETE`；重复发布返回既有记录 |
| 快照稳定 | 深度优先、固定字段顺序、金额 scale 固定、SHA-256；同输入两次结果一致 |
| 租户隔离 | MyBatis 租户行插件；跨租户资源按 ID 查询返回 404 语义 |
| 内网端点 | 不挂功能权限；`InternalTokenFilter` 校验内网令牌；网关对 `/pdm/internal/**` 外部请求 deny |

## 5. 风险与遗留

| 风险 | 影响 | 处置 |
|---|---|---|
| 分类种子仅租户 1 | 新租户无预置分类，需手工建根分类 | 开通租户时补种子，或提供租户初始化钩子 |
| 发布快照为全量冻结 | 超大型 BOM 发布时序列化耗时 | M1B 对比/导出再做异步化；当前按 1 万节点评估 |
| 树查询一次装载全量 | 超大 BOM 详情响应较大 | M1B 引入懒加载/分页展开 |
| 内网端点依赖网关 | 若网关未配置 `internal-deny`，外网可访问 | 上线前核对网关规则；服务端仍校验内网令牌 |
| 权限区间 930–939 | 计划原写 930–949，M1A 实际使用 930–939 | 940–949 预留给 M1B/M2，避免返工 |
| 零件未挂接文档版本 | 无法从零件跳转图纸版本 | 留待 M2 与变更域联动 |
