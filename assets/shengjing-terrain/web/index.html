制作规格

① 山脉层

南岭主脉横贯南缘（最高约 460m，仅最高峰带雪线）；东山丘陵居东，留东关垭口；西缘缓丘作河湾阶地观感。

② 平原与台地

北岸冲积平原 25±m 带田块棋盘；圣京圆形台地三级环带 80 / 62 / 45m，城高于四周。

③ 水系层

北江沿北部平原东西向，江湾在城东北向城凸出（离城墙约 500m）；玉溪 / 清溪 / 云川三支流自南岭垭口向北汇流；北岸两条辫状支汊；圣京北门运河直通北江，南渠出城南门。

④ 地貌与植被

平原草地农田、河道两侧滩湿地、岩体坡面、南岭密林与平原疏林。

⑤ 城池关隘

圣京三层城墙（外城 / 内城 / 皇城）+ 金顶主殿；东关、南关、北关三处哨塔；四处预留区虚线框（外部平原 / 宫城核心 / 东山关隘 / 南岭山脉）。
